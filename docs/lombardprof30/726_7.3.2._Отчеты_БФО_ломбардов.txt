# 7.3.2. Отчеты БФО ломбардов



Для
отчетов БФО механизм создания и работы универсальный и во многом повторяет
порядок, описанный в разделе Бухгалтерский баланс (код 0420901) данного
руководства:



● 
Отчет о
финансовых результатах НФО (код 0420902);



● Отчет об изменении собственного капитала НФО (код 0420903),



● Отчет о потоках денежных средств НФО (код 0420904) и
примечание к БФО



Все формы БФО для ломбардов
создаются из встроенного Комплекта отчетности бухгалтерской (финанасовой)
отчетности.









При обращении по
ссылке открывается форма списка Комплекта
отчетности. Далее следует обратиться к разделу программы Бухгалтерская
(финанасовая) отчетность по 844-П, выбрать форму отчета, при необходимости
определить период и вид отчетности, далее выполнить команду Создать с
установленным курсором на директории с выбранным комплектов отчетов БФО.



Все созданные отчеты
БФО заполняются автоматически данными из учетной системы при вполнении
команды по кнопке Заполнить.







## Отчет о финансовых результатах НФО (0420902)



Отчет о финансовых результатах НФО (код 0420902) имеет
содержит сведения о финансовых результататх организации, форма заполняется
автоматически по данным учета и установленных настроек формы.







## Отчет об изменениях собственного капитала НФО (0420902)



Отчет об изменении
собственного капитала НФО (0420902) содержит сведения об изменениях в активах
организации, форма заполняется автоматически по данным учета установленных
настроек формы.














## Отчет о потоках денежных средств НФО (код 0420904)



Отчет об изменении
собственного капитала НФО (0420904) заполняется автоматически по данным учета
установленных настроек формы.
