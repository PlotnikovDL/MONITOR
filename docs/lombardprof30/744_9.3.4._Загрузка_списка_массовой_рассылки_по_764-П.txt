# 9.3.4. Загрузка списка массовой рассылки по 764-П



Загрузка списка выполняется с помощью
команды Загрузить список массовой рассылки по 764-П из формы списка
справочника.






В форме загрузки необходимо указать файл
для загрузки. На форме загрузки также отображается информация о дате последней загрузки.






При выполнении загрузки происходят следующие
действия:



● Обрабатываются элементы справочника Массовая рассылка по
764-П:



- 
создаются новые, в
случае их отсутствия в файле загрузки;



- 
изменяются существующие,
в случае нахождения различий с данными файла;



- 
помечаются на удаление,
в случае отсутствия данных по этим лицам в файле загрузки.



● для элементов справочников Физические лица и Контрагенты
заполняется реквизит Дата включения в механизм проверки по списку массовой рассылки
по 764-П, если он пустой;



● в случае нахождения соответствия клиентов ломбарда со списком
массовой рассылки по 764-П создаются соответствующие записи в регистре сведений
История проверки по списку массовой рассылки по 764-П.



При успешном завершении загрузки создается
запись в регистре сведений История тотальных проверок клиентов на дату проверки
и указанием информации о дате загруженного списка массовой рассылки по 764-П.
