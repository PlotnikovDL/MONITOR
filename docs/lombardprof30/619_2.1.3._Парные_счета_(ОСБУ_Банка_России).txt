# 2.1.3. Парные счета (ОСБУ Банка России)



Парные счета — это пара лицевых счетов,
один из которых активный, а второй — пассивный, каждая пара лицевых счетов служит
для отражения однородных фактов деятельности, поэтому по итогу закрытия парных счетов
только один счет из пары может иметь остаток, а второй счет всегда будет с нулевой
суммой.



Список парных счетов хранится в регистре
Парные счета.



Парными являются не все счета. Список
парных счетов определяется Положением ЦБ РФ № 803–П.



Список заданных в системе парных счетов
можно посмотреть путем выбора на панели разделов программы Администрирование и настройка НФО — Настройки — Парные счета.






Для заполнения парных счетов необходимо
выполнить команду Заполнить и
ввести дату заполнения. Если возникает необходимость добавить парные счета, то их
можно добавить в данный регистр с помощью команды Создать.
