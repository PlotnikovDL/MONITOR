# 4.3. Справочник «Гарантии и поручительства»



Справочник Гарантии и поручительства предназначен для ведения аналитического
учета на определенных счетах по гарантиям и поручительства. Значения
справочника используются при осуществлении записи хозяйственных операций по
счетам 60315, 91315, 91414.






При заполнении указываются следующие
реквизиты:



● Код — код элемента, значение реквизита устанавливается
автоматически;



● Наименование — наименование гарантии и поручительства,
значение задается произвольно;



● Номер — номер договора поручительства;



● Дата — дата договора поручительства;



● Поручитель — указывается поручитель по договору из
справочника Контрагенты;



● Поручаемый — указывается поручаемый по договору из
справочника Контрагенты.
