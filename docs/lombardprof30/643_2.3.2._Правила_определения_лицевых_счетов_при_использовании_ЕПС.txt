# 2.3.2. Правила определения лицевых счетов при использовании ЕПС



Для того, чтобы установить правила определения
лицевых счетов следует перейти в регистр Правила определения лицевых счетов.






Ввод нового правила для определения лицевых
счетов производится по команде Создать.






В открывшейся форме для изменения правил
определения лицевых счетов требуется заполнить следующие реквизиты:



● Период — указывается дата начала действия правила, после
этой даты будут действовать правила определения лицевых счетов;



● Организация — заполняется организация, для которой будет
действовать правило, если не заполнять, указанное правило будет действовать для
любой организации;



● Счет и Счет ЕПС — задаётся соответствие счетов учета;



● Фильтр — при необходимости устанавливается правило отбора
проводки.
