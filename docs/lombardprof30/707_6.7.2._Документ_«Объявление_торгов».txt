# 6.7.2. Документ «Объявление торгов»



Для отражения результатов объявления торгов
и формирования лотов, участвующих в торгах используется документ Объявление торгов.



В торгах могут участвовать физические
и юридические лица. Задаток, для участия в торгах, не требуется. Количество
заявок на лоты от одного участника не ограничено. Торги проводятся по отдельным
лотам. Лот состоит из одного изделия или нескольких изделий. Выигравшим торги,
признается лицо, заявившее максимальную цену за данный лот. Сроки (дата)
проведения торгов устанавливаются на основании решения организации.



Обратиться к списку документов можно путем
выбора ссылки Объявление торгов
на панели разделов программы Ломбард
— Торги.






Для ввода в список нового документа
следует выполнить команду Создать.






В открывшейся форме документ Объявление торгов заполняются поля Дата торгов и Подразделение.






Далее следует подобрать договоры.
Подбор договора можно выполнять самостоятельно, выбрав контрагента и договор (в
список выбора попадут только договоры, у которых истек льготный период) или
автоматически по команде Подобрать лоты.












В результате выполнения команды Подобрать
лоты в документе заполняются табличные части документа:



1) 
Верхняя табличная
часть содержит сведения по контрагенту, договору, залоговое изделие по которому
передается на торги, по номеру лота и стоимости договора в лоте.



При этом реквизит Лот должен
быть заполнен пользователем или вручную, или при помощи команды Заполнить
– Заполнить номера лотов по номеру договора, а реквизит Цена
договора заполняется автоматически в случае, если в документе Передача
на реализацию по этому залоговому изделию была установлена цена реализации.
В противном случае стоимость реализации указывается пользователем вручную.



2) 
Нижняя табличная
часть содержит сведения о залоговом изделии, которое передается на торги.






После объявления торгов, нужно
провести торги. Для этого нужно выполнить команду по кнопке Создать на основании и в выпадающем
списке выбрать пункт Проведение
торгов.
