# 10.2.3. Получение сведений из ГИИС ДМДК



После завершения процедур маркировки и
опробования изделий в личном кабинете ГИИС ДМДК для квитанции присваивается один
из следующих статусов:



● Ценности возвращены сдатчику;



● Ценности готовы к выдаче;



● Ценности возвращены по инициативе сдатчика.



Уже после присвоения одного из указанных
статусов из системы «1С:Ломбард» можно отправить следующий запрос на получение обратной
стороны квитанции по команде в операциях с ГИИС ДМДК по команде 3.Запросить
обратную сторону квитанции в ГИИС (для отправки запроса в ГИИС ДМДК потребуется
его подписание электронной подписью).





Важно! Для
обновления статуса квитанций режим пакетной загрузки ГИИС ДМДК не предусмотрен,
в связи с чем, каждый запрос необходимо формировать и подписывать по каждой квитанции.
