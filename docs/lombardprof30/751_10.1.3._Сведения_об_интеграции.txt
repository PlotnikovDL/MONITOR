# 10.1.3. Сведения об интеграции



В разделе Ломбард: Настройки существует отдельный раздел ГИИС ДМДК. В этом разделе
размещена обработка Операции с ГИИС ДМДК для выполнения
всех необходимых операций обмена данными с ГИИС ДМДК. Для обеспечения обмена с
обработки данных по ГИИС ДМДК в системе представлены следующие объекты:



● справочник Ювелирные изделия ГИИС ДМДК;



● справочник Бренды ГИИС ДМДК;



● справочник Виды драгоценных камней ГИИС ДМДК;



● документ Инвентаризация ГИИС;



● документ Акт инвентаризации ГИИС ДМДК;



● документ Квитанция на опробование ГИИС ДМДК;



● документ Преобразование партий в лом;



● документ Спецификация ГИИС ДМДК (исходящая);



● документ Операции над объектами в ГИИС ДМДК;



● отчет Информация по изделиям ГИИС ДМДК;



● отчет Информация по партиям изделии ГИИС ДМДК;



● регистр сведении Партии ювелирных изделии ГИИС ДМДК.
