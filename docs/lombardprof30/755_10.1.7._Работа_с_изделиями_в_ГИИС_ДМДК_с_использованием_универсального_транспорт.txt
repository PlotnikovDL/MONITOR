# 10.1.7. Работа с изделиями в ГИИС ДМДК с использованием универсального транспортного модуля (УТМ)




## Требования к подключению универсального транспортного модуля.



Настройка универсального транспортного
модуля (УТМ) производится на каждом компьютере, с которого планируется отправка
данных.



Данные, передаваемые с использованием
УТМ, отправляются до момента отправки чека ККМ. В случае успешной проверки
пробивается непосредственно чек ККМ, а в случае обнаружения ошибки в результате
проверки — выводится сообщение об ошибке.



Все направленные запросы на проверку
записываются в регистре сведений Данные обмена ТМ с ГИИС ДМДК.



Для функционирования УТМ рекомендуется
использовать отдельный персональный компьютер со следующими минимальными характеристиками:



● процессор x64 с частотой от 1,5 ГГц и выше;



● ОЗУ от 512МБ или более;



● Ethernet-контроллер, 100/1000 Mbps;



● дисковый накопитель общим объемом не менее 50 Гб.



Для работы с УТМ поддерживаются
64-битные операционные системы:



● 
ОС Microsoft Windows
10, Windows 11, Windows Server 2016;



● Astra Linux 1.7, Ubuntu 22.04, Debian 11.8.



Контрольно-кассовая техника должна
находиться в одной сети с данным компьютером, через который выполняется обмен с
использованием УТМ.




## Настройка нового подключения УТМ



Когда выполнены все предварительные
условия подключения к системе ГИИС ДМДК (см. раздел руководства Подготовка
к работе с ГИИС ДМДК)
необходимо создать подключение к информационной системе для работы с
универсальным транспортным модулем. Для этого необходимо:



● выбрать команду создать на форме списка Настройки ТМ
ГИИС ДМДК;



● в открывшейся форме установить требуемую организацию и
подразделение;



● указать дату начала отправки чеков в ГИИС ДМДК;



● установить адрес подключения к транспортному модулю
(при создании нового подключения, по умолчанию заполняется адрес 127.0.0.1
и устанавливается порт 9999, адрес и порт меняется в зависимости от того, на
каком компьютере установлен транспортный модуль – ТМ);



● применить настройку Отправлять на клиенте;



● проверить подключение к транспортному модулю по
соответствующей команде на форме;



● после успешной проверки подключения применить команду Записать
или Записать и закрыть.







## Проверка подключений УТМ



В решении «1С:Ломбард» можно посмотреть
и проверить подключение УТМ. Проверка выполняется из раздела программы Ломбард:
Настройки – группа Транспортный модуль ГИИС ДМДК при обращении к выбранной
строке с параметрами Настройки ТМ ГИИС ДМДК.
