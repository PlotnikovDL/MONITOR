# 6.9.1. Рабочее место товароведа: операция «Выдача займа»



Выдача займа форме Рабочее место
товароведа производится по команде Выдача займа, получение залога.
При этом следует обратить внимание на влияние отбора по физическому лицу-заемщику
и на последующее заполнение документа Выдача займа, получение залога:



● в случае, если отбор по физическому лицу не установлен,
форму документа по выдаче займа потребуется заполнять полностью;



● в случае, если отбор по физическому лицу установлен, форма
документа по выдаче займа будет заполнена данными выбранного в отборе физического
лица.






Порядок заполнения документа Выдачи
займа, получения залогового билета при работе из формы Рабочее место
товароведа будет следующий:



1. 
Заполняются
общие сведения по залоговому билету и условия предоставления займа:



● Номер и Дата — устанавливаются системой автоматически;



● Проверяются значения полей Организация, Склад,
Подразделение (эти поля могут быть предварительно заполнены при условии наличия
уже настроенных параметров по ограничению прав для пользователя, выполняющего текущую
операцию);



● Залоговый билет — заполняется автоматически значением из
списка залоговых билетов по договору;



● Подбор бланка — операция подбора производится вручную из
доступного списка бланков по команде Подбор бланка или выполняется системой
автоматически при попытке обновить (при активированном значении Автоматический подбор
бланков в настройках Параметры учета операций по залогу и займу при создании документа
Выдача займа, получение залога сам бланк подбирается системой автоматически);



● Заемщик — значение в поле заполняется автоматически при
создании документа или производится пользователем вручную путем выбора заемщика
из справочника физических лиц, в случае, когда физическое лицо — это новый заемщик
ломбарда, тогда необходимо создать новое физическое лицо и заполнить его карточку
(для нового клиента обязательно должны быть заполнены полное имя заемщика, вкладки
Главное и Анкетные данные клиента, другие вкладки к заполнению не обязательны);












В дальнейшем сведения из карточки
физического лица передаются в документ выдачи займа.






Кроме этого, следует также заполнить:



● Тип изделий — выбирается наименование типа изделия из
выпадающего списка, соответствующее изделию, принимаемому в залог;



● Форма оплаты — выбирается значение Наличные при
выдаче займа наличными средствами или по платежной карте, По карте – при
перечислении займа по реквизитам банковской карты;



● Условия договора — устанавливаются требуемые условия
договора и начисления процентов;



● Срок (дней) — устанавливается срок, на который
выдается заем;



● Дата окончания и Льготный период — значения
устанавливаются автоматически системой.



2. Заполняется информация по номенклатуре.



Добавление номенклатуры в список Предметы
залога производится по команде Добавить, после чего открывается
форма заполнения номенклатуры (форма может различаться в зависимости от выбранного
значения Тип изделия в залоговом билете).









В открывшейся форме заполняются
поля:



● Тип изделия — значение заполняется автоматически при
создании номенклатуры;



● Артикул — значение присваивается автоматически при
записи изменений в номенклатуре;



● 
Вид изделий —
значение выбирается пользователем из ранее заполненного справочника;



● Шаблон изделия — значение подбирается пользователем из
ранее заполненных и подготовленных шаблонов заполнения номенклатуры (необязательный
реквизит);



● Состояние — значение подбирается пользователем из ранее
заполненного справочника (необязательный реквизит);



● Договор — заполняется автоматически;



● Значения Наименование и Полное наименование формируются
автоматически в процессе заполнения карточки номенклатуры;



● Металл — значение выбирается пользователем из ранее заполненного
справочника;



● Проба — выбирается пользователем из ранее заполненного
справочника;



● Общий вес — значение устанавливается пользователем;



● Вставки ГИИС ДМДК — значение устанавливается в случае, если принимаемое
в залог ювелирное изделие имеет вставки из драгоценных камней;



● Именник (обязательное клеймо-шифр на ювелирных
изделиях, которое содержит уникальную комбинацию букв, указывающих на год
изготовления, территориальную инспекцию пробирного надзора и самого
изготовителя, служащее гарантией подлинности и происхождения украшения) — значение
заполняется пользователем;



● Вес вставок — значение заполняется автоматически при заполнении
вставок в ГИИС ДМДК;



● Чистый вес — значение заполняется автоматически;



● Дополнительная классификация — значение
устанавливается пользователем самостоятельно;



● Код ОКПД — значение заполняется пользователем;



● Гиперссылка Дефекты — открывает дополнительную
форму, которая заполняется пользователем по необходимости.



3. 
После
добавления позиций номенклатуры и заполнения шапки документа



Выполняется команда Рассчитать
и выполняется проверка заполнения карточки номенклатуры, далее следующая
команда Записать и закрыть.





Важно! После записи карточки номенклатуры внесение изменений
становится недоступным.






4. 
После
заполнения номенклатуры в форме документа
Выдача займа получение залога



Выполняется проверка корректности полей
табличной части документа:



● Количество;



● Оценка за ед.;



● Оценка предмета;



● Сумма займа.



После проверки необходимо выбрать и
использовать команду Расчет начислений по займу, а затем Провести.



После проведения документа можно вывести
на печать требуемые документы для клиента используя встроенное меню по кнопке Печать:



● Залоговый билет:



● Акт приема-передачи имущества;



● Согласие на обработку персональных данных;



● Анкета клиента.



5. 
Создается на
основании документа выдачи займа кассовый документ по выдаче наличных или Операция
по платежной карте.






При создании документов на основании
заполнение происходит автоматически, достаточно проверить корректность
заполнения и выполнить далее команду Провести или Провести
и закрыть. При наличии подключенного платежного оборудования
производится печать чека при обращении к кнопке Чек.
