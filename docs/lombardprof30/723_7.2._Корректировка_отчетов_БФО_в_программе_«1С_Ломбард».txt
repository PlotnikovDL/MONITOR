# 7.2. Корректировка отчетов БФО в программе «1С:Ломбард»



Для формирования отчетности по ломбардам,
необходимо настроить/откорректировать Макет отчетных форм,
созданный для разнообразных НФО, под специфику деятельности и отчетности ломбардов,
в соответствии в Указание ЦБ РФ от 27.09.2024 N 6869-У, так как отчетность
установлена для всех видов НФО, но у ломбардов существует своя специфика, которая
требует необходимости ее настроить.



Данная возможность предоставляется в
специальном подразделе Настройки и справочники раздела Отчеты НФО.






Перед корректировкой отчетов необходимо
вначале открыть макет формы. Макеты располагаются в разделе программы Отчеты НФО — Настройки и справочники по ссылке Макеты
отчетных форм.









В открывшемся окне слева располагается
список с основными отчетными формами (папки, в которых расположены основными формы
и примечания), справа представлены сами макеты форм.






Для редактирования отчета необходимо
открыть требуемый макет отчетной формы и перейти на закладку Настройки макета.






В открывшейся форме выбирается необходимая
ячейка формы и после выбора открывается окно со счетами, которые входят расчет этой
ячейки.






Если
требуется добавить в список уже имеющийся счет, его нужно просто перетащить в окно
из списка справа. Если нужно убрать счет, то его нужно удалить и из формулы, и из
окна списка счетов.



Если необходимо добавить счет, который
отсутствует в форме списка, то необходимо выполнить следующие действия:



● в меню слева раскрыть строку Показатели по данным учета;



● выбрать счет и завершить выбор двойным щелчком мыши;






● при выборе счета откроется форма настройки счета, к
которой необходимо выбрать для получения данных один из типов итогов «оборот»
или «сальдо», и период получения данных «на конец» или «на начало»;






● для получения точных данных также добавляется отбор по
объектам аналитического учета по имеющимся на счете субконто, достаточно
использовать команду Добавить элемент, выбрать нужный элемент для отбора,
задать вид сравнения и выбрать конкретные значения для отбора.






После установки всех необходимых
параметров выполняется команда Закончить редактирование во всех открытых
окнах и затем также в форме макета отчета выполняется команда по кнопке Записать
и закрыть. После записи выполняется открытие макета и его проверка по
команде Проверить макет, проверяется полученный результат.
