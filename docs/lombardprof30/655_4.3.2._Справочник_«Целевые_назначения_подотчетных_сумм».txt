# 4.3.2. Справочник «Целевые назначения подотчетных сумм»



Справочник Целевые назначения подотчетных сумм предназначен для ведения аналитического
учета на определенных счетах сумм, выданных подотчетному лицу по видам целевых назначений.
Значения справочника используются при осуществлении записи хозяйственных операций
по счетам 60307, 60308.






В качестве значений для поля Наименование указывается целевое назначение
подотчетных сумм.
