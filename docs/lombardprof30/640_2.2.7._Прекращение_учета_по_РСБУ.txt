# 2.2.7. Прекращение учета по РСБУ



При ведении учета в переходный период
возникает необходимость часть документов вводить со старыми датами (по РСБУ), остальные,
как и положено, с текущей датой (по ОСБУ). 



В таком случае организации необходимо
установить дату, с которой документы будут вводиться по новому плану счетов. Открыть
и задать окончание учета по новым стандартам можно путем выбора на панели разделов
программы Администрирование и настройка НФО
— Сервис ссылки Окончание учета по старым
стандартам.






Откроется
форма документа Окончание учета по новым
стандартам. Дата задается пользователем самостоятельно,
на свое усмотрение в зависимости от того, когда планируется закрыть год по
операциям РСБУ.






После заполнения поля Окончание
учета по старым стандартам с установленной даты все документы будут вводиться
и записываться только с отражением операций по новому плану счетов.



Если документ вводится до даты окончания
учета по старым стандартам, будет формироваться диалоговое окно, в котором необходимо
будет ввести дату документа. Если дата документа будет раньше даты начала ведения
учета по ОСБУ для НФО, то данные в форме документа и проводки будут относиться к
учету по РСБУ. Во всех остальных случаях (в том числе и тогда, когда дата окончания
учета по старым стандартам заполнена не будет) документ полностью формируется в
соответствии с ОСБУ, записи хозяйственных операций ведутся только по ЕПС, начиная
с даты начала ведения учета по операциям НФО.
