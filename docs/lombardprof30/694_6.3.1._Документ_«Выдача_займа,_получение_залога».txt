# 6.3.1. Документ «Выдача займа, получение залога»



Документ предназначен для регистрации
займа под залог. Документ используется для регистрации сделки, при которой ломбард
берет залог, а залогодатель получает деньги.



Обращение к списку документов выполняется
путем выбора ссылки Выдача займа, получение залога на
панели разделов Ломбард — Займы и залоги.






Для отражения операции займа необходимо:



● заполнить основные реквизиты заемщика и условия займа (заемщик,
срок предоставления займа, тип залоговых изделий и т.п.);



● заполнить описание передаваемых в залог предметов;



● выбрать схему расчета;



● выполнить расчета плановых начислений по займу по команде
Расчет начислений по займу».



При вводе документа по выдаче займа
выполняется запись следующих данных:






● Номер — порядковый номер документа, заполняется автоматически;



● От — дата операции;



● Организация — залогодержатель;



● Склад — место хранения или нахождения залогового
билета;



● Подразделение — подразделение организации, где будут
отражаться операции по выдаче займа и получению залога;



● Залоговый билет – поле автоматически заполняется
значением Залоговый билет;



● Подбор бланка — позволяет вручную подобрать Залоговый
билет из списка;



● Кнопка «обновить» с изображением стрелки по кругу — команда
на автоматический подбор первого свободного по списку Залогового билета;



● Заемщик — указывается фамилия, имя и отчество (при
наличии) заемщика;



● Срок (дней) — количество дней, на который
предоставляется займ;



● Дата погашения — дата погашения займа, значение рассчитывается
автоматически;



● Льготный период — это период, в течение которого
ломбард обязан хранить имущество заёмщика после окончания срока договора, в
указанный период ломбард не имеет права обращать взыскание на залоговые
изделия;



● Выбрать условия займа — выбирается подходящее условие
займа и установленных;



● Номенклатура — указывается номенклатура, которую сдает
залогодатель;



● Единица — отражается единица измерения для
номенклатуры;



● Количество — указываем количество изделий
номенклатуры;



● Оценка за ед. — указывается на какую сумму
залогодержатель оценил объект номенклатуры;



● Оценка залога — результат умножения количества изделий
на оценку за единицу этого изделия;



● Сумма займа — указывается сумма займа, предоставляемая
заёмщику под обеспечение залогом;



● Счет учета — указывается счет учета предмета залога;



● Расчет начислений по займу — команда, которую
необходимо выполнить после заполнения формы данными, в результате произойдет
расчет процентов за пользование займом, которые можно посмотреть, нажав на
соответствующую гиперссылку;






● Доп. услуги — значения могут быть заполнены вручную
или рассчитаны автоматически, когда, помимо процентов, в схеме условий займа
есть фиксированные платежи в виде разовых услуг (например, сумма за хранение
или оценку изделия, которая взимается вначале в соответствии с выбранной схемой
займа).



В случае, если в условиях займа
помимо процентной ставки присутствуют дополнительные консультационные или
информационные услуги, при пересчете условий займа автоматически
рассчитывается, например, сумма за оценку изделия, которая взимается вначале в
соответствии с выбранной схемы займа.



Для отражения начисления
дополнительных услуг в учете необходимо сформировать Акт расчета — после
появления доп. услуг будет активна кнопка Выписать
акт расчета. При обращении к кнопке с надписью Выписать акт расчета автоматически создается документ реализации на
сумму дополнительных услуг.






В результате записи и проведения
документа Выдача займа, получение залога
осуществляется запись хозяйственных операций на счетах учета (по ЕПС и
(или) по РСБУ) регистры хранения информации:



● Учет предоставленных займов;



● ПСК по договорам займа;



● Состояние залогового билета;



● Состояние бланков;



● Условия предоставления займов.



При записи и проведения документа Выдача займа, получение залога в РСБУ
создаются проводки:



● по оприходованию суммы залога на дебет счета 008.1
«Обеспечения обязательств и платежей полученные»;



● по списанию бланков строгой отчетности по кредиту счета
006 «Бланки строгой отчетности».






При проведении документа Выдача займа, получение залога в
регистре бухгалтерии, предназначенном для отражения операций по счетам ЕПС,
создаются проводки:








Важно! При записи и проведении документа Выдача займа, получение залога для
последующего учета взаиморасчетов автоматически создается новая запись по
контрагенту и новая запись по договору с этим контрагентом.






Для формы документа Выдача займа получение залога
предусмотрена возможность печати Залогового
билета.






На основании документа Выдача займа, получение залога по
команде Создать на основании
формируется кассовый документ Выдача наличных
(на размер займа, документ заполняется автоматически). При наличии
дополнительных услуг, требующих оплаты при предоставлении займа, на основании
документа формируется кассовый документ Принятие
наличных (сумма оплаты залогодателя за дополнительные услуги, заполняется
автоматически).
