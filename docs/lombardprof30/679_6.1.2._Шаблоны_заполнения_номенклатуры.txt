# 6.1.2. Шаблоны заполнения номенклатуры



Шаблоны заполнения номенклатуры предназначены для
оперативного ввода, обработки и хранения информации по предметам залога и
вещей, принятых на хранение.



Открывается справочник Номенклатура
из раздела программ Ломбард. Настройки —
Учет предметов залога и вещей на хранении по ссылке Шаблоны заполнения
номенклатуры.









Для создания нового элемента Шаблоны заполнения номенклатуры из формы списка по кнопке Создать
или через пиктограмму









После записи нового
документа Шаблоны заполнения
номенклатуры, ему автоматически присваивается код – системный номер
справочника.



При заполнении
реквизитов документа Шаблоны заполнения номенклатуры следует обратить
внимание на следующие информационные поля:






● Тип изделия — справочник с заданными типами изделий
(ювелирное, автомобиль, мех, прочее);



● Состояние — элемент справочника состояния,
описывающего стандартное состояние изделия (Новый в упаковке, загрязненный,
лом и т.д.).



Для разных типов изделий указываются
присущие им характеристики, например, для ювелирных изделий:



● Металл — указывается значение из справочника Металлы
для типа изделия, определенного как «Ювелирное изделие»;



● Проба — указывается значение из справочника Пробы для
типа изделия, определенного как «Ювелирное изделие»;



● Вес — включая общий вес, чистый вес и вес вставок.
