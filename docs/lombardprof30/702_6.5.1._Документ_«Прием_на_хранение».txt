# 6.5.1. Документ «Прием на хранение»



Документ Прием на хранение предназначен для отражения операций приема вещей на
хранение. Создание документа выполняется из списка Прием на хранение, расположенного в разделе программы Ломбард — Хранение.






Документ создается командой по кнопке Прием на хранение из одноименной
формы списка.






Для отражения операции в системе по документу Прием на хранение необходимо:



● заполнить основные реквизиты клиента и условия
хранения (поклажедатель, срок хранения, тип изделий и т.п.);



● заполнить описание вещей, передаваемых на хранение;



● выбрать схему расчета. 






После изменении основных данных
необходимо выполнить команду Рассчитать стоимость для отражения
произведенных изменений в схеме расчета.



Для отражения операций по начислению
дополнительных услуг в учете необходимо сформировать документ Акт расчета (если хранение оплачивается
при получении вещей), а после выбора условий хранения будет активна команда Выписать
акт расчета. При её выполнении будет автоматически создаваться документ
по реализации на сумму услуг.



В результате записи и проведения
документа Прием на хранение
осуществляется запись хозяйственных операций на счетах учёта (РСБУ и ЕПС) и формируются
следующие проводки:



1) проводки по РСБУ:



● при принятии вещей на хранение по Дт забалансового
счета 002 «Товарно-материальные ценности, принятые на ответственное хранение»;



● списание бланка сохранной квитанции по Кт
забалансового счета 006 «Бланки строгой отчетности»;






2) Проводки ЕПС:



● по учету принятых вещей на хранение делают движение по
Дт счета 91202 «Разные ценности и
документы» в Кт счета 99999 «Счет для корреспонденции с активными счетами при
двойной записи»;



● списание бланка строгой отчетности по Дт счета 99999
«Счет для корреспонденции с активными счетами при двойной записи» и по Кт счета
91223 «Бланки строгой отчетности»






В
случае оплаты услуг при приеме на
хранение, необходимо также сформировать кассовый документ Поступление
наличных. Документ создается командой из
встроенного меню по кнопке Создать на основании (сумма оплаты за услуги
хранения заполняется автоматически).



Из документа Прием на хранение предусмотрена возможность печати сохранной
квитанции, а также Согласие на обработку персональных данных.
