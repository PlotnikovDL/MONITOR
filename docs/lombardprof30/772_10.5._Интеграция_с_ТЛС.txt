# 10.5. Интеграция с ТЛС



Специализированная обработка по
интеграции с ТЛС загрузить данные из АСУТП «Ломбард» (автоматизированная система
управления технологическим процессом «Ломбард»).



Вызов обработки выполняется из
раздела программы Ломбард — Сервис по
ссылке Загрузка данных из АСУТП Ломбард.






На форме в группе Настройка загрузки выполняется
установка основных параметров и заполняется следующая информация:






● Файл для загрузки — имя файла, из которого осуществляется
загрузка (формат файла *.dbf).



● Кодировка — кодировка данных файла.



● Организация — организация, для которой осуществляется загрузка
данных.



● Подразделение — подразделение, по которому загружаются
данные.



В секции Данные для загрузки находится таблица проводок (автоматически заполняется
по данным файла при нажатии на кнопку Загрузить
данные).



Под таблицей Данные для загрузки находится гиперссылка Документы «Операция». Если требуется загрузить проводки в определенный
документ Операция, этот документ следует выбрать по этой гиперссылке. Если документ
не выбирается, обработкой автоматически сформируются документы Операция
с группировкой по датам.



Для того чтобы перевыбрать документ Операция необходимо воспользоваться гиперссылкой
Очистить,
находящейся рядом.



По команде Записать операцию будут сформированы
документы Операция, документы можно посмотреть
по гиперссылке Документ «Операция».



В случае, когда не всю аналитику удалось
сопоставить с данными в информационной базе, становится доступна кнопка Настроить
сопоставление. При нажатии на нее открывается закладка настроек сопоставления,
где отображены следующие данные:



● Наименование — наименование аналитики (счета), как оно есть в файле
для загрузки;



● Значение — значение, которое необходимо сопоставить.



Также на данной закладке доступна настройка,
каким образом действовать для не сопоставленных элементов:



● Создавать — не сопоставленная аналитика будет создана;



● Пропускать — не сопоставленная аналитика будет пропущена.



При сопоставлении значений на закладке
основных настроек соответствующие позиции аналитик в таблице загружаемых данных
будут заполнены сопоставленными значениями.
