# 10.1.6. Закладка «Операции с партиями и изделиями»



На вкладке Операции с партиями и изделиями
выполняются операции по передаче данных в ГИИС ДМК партиями в разрезе изделий и
поштучно.





Важно! Предварительная регистрация партии полуфабрикатов требуется
только для случая применения агрегированной партии изделий (с количеством больше
единицы). В случае поштучной регистрации ювелирных изделий предварительная регистрация
партии полуфабрикатов с количеством равным единице не требуется, при этом выданный
системой ИНП партии и является одновременно УИН.






Командой по кнопке Заполнить список
партии выполняется заполняются сведения по изделиям учетом наличия остатков
в регистрах накоплений Учет предоставленных займов и Изделия на реализацию.



Ювелирные изделия можно регистрировать
и как «партии», и как «изделия». Для этого необходимо выполнить переключить «тумблер»
Регистрировать как: в положение Изделие либо
положение Партия.






Для обработки информации необходимо обязательно
заполнить группу реквизитов Параметры заполнения, а именно: Этап обработки,
Тип партии, Вид партии и ОКПД2. Если при заполнении указано
значение этапа обработки как Оборот на территории РФ, необходимо установить
признак Ввод остатков. В табличной части сведений по изделиям обязательно
должны быть заполнены все данные, кроме УИН (если только не выполняется повторная
передача данных на корректировку по партиям или изделиям в ГИИС).



Когда все данные по изделиям
заполнены, далее выполняются следующие этапы процесса:



1. Производится Запрос на регистрацию пакета партий, или
выполняется отправка данных на регистрацию партий или изделия в ГИИС и
получение Уникального идентификатора для изделия (UUID). Запрос осуществляется
по кнопке Запрос на регистрацию пакета партий. Указанный запрос необходимо
подписать электронной подписью участника обмена. Данные по запросу записываются
в регистр сведений Запросы на регистрацию пакета партий ГИИС ДМДК.



2.Получить результат запроса на
регистрацию пакета партий – этот вторым
этапом обработки является получением ответа от ГИИС ДМДК. Действие выполняется
по соответствующей кнопке на основе данных из регистра сведений Запросы на
регистрацию пакета партий ГИИС ДМДК. В систему отправляются данные для
направленных ранее объектов при регистрации партии. Запрос на получение
результата также необходимо подписать электронной подписью. Результат
выполнения можно посмотреть в регистре сведений Партии изделий ДМДК в ГИИС
ДМДК или через личный кабинет пользователя в системе.




## Закладка «Операции с присвоением УИН изделиям в 1С на основе партий»



На основе уже введенных партий у ГИИС
ДМДК запрашивается список УИН для присвоения их изделиям в системе «1С:Ломбард».
Действие выполняется на закладке Операции с присвоением УИН изделиям в 1С на
основе партий.



Командой по кнопке Получить список
INP/UIN заполняются ИНП для партии из регистра сведении Партии ювелирных
изделий ГИИС ДМДК установленным признаком Исполнен равным
значению «Ложь», т.е. по тем ИНП у партий, для которых запрос на получение
списка УИН не выполнялся. Для уточнения информации пользователь имеет
возможность открыть список записей регистра по ссылке Партии ювелирных
изделий ГИИС ДМДК из раздела программы Ломбард:Настройки – ГИИС
ДМДК.









Каждую запись
в регистре пользователь может открыть и уточнить все необходимые сведения о
ней.






Данные из регистра сведений Партии
ювелирных изделий ГИИС ДМДК в табличную часть обработки необходимо
заполнить самостоятельно. При заполнении необходимо контролировать, что все
данные в табличной части заполнены. Для дальнейшей работы необходимо
обязательно выбрать значение в поле Способ присвоения УИН изделиям. На
основе этого параметра при получении списка УИН программа присвоит УИН изделиям.
Так, например, если отправить запрос на получение УИН только по реализованным
изделиям, то УИН в системе 1С присвоится только тем изделиям, которые находятся
на реализации.






Когда все данные по изделиям
заполнены, для отправки запроса необходимо выполнить запрос по кнопке 1.Запрос
на получение УИН изделий. Выполняется отправка данных на регистрацию
изделия в ГИИС и получение Уникального идентификатора для изделия (UUID).
Указанный запрос необходимо подписать электронной подписью участника обмена.
Данные по запросу записываются в регистр сведений Запросы на
получение списка изделии ГИИС ДМДК.



Для
получения результата необходимо выполнить команду по кнопке 2. Получить
результат запроса УИН изделии. Отправляется новый запрос на получение
списка УИН изделий на основе данных регистра сведений Запросы на получение
списка изделии ГИИС ДМДК. Запрос подписывается электронной подписью
участника обмена Результат можно посмотреть в регистре сведений Изделия ГИИС
ДМДК.



Список изделий с присвоенными УИН
можно увидеть в регистре сведений Ювелирные изделия ГИИС ДМДК.









В системе
предусмотрена возможность открытия карточки изделия и посмотреть всю
необходимую информацию, которая
принимает участие в обмене.







## Операции с присвоением УИН изделиям в ГИИС ДМДК на основе партии



На вкладке Операции с присвоением
УИН изделиям в ГИИС ДМДК на основе партии выполняются операции по
присвоению УИН изделиям в ГИИС ДМДК на основе данных, хранящихся в системе «1С:Ломбард».



По кнопке Получить изделия с УИН
заполняются УИН/ИНП сведения по данным регистра сведений Изделия ГИИС ДМДК,
которые еще не были отправлены на регистрацию в ГИИС.






Когда все данные по изделиям
заполнены, далее необходимо выполнить 1. Запрос на регистрацию изделия в
ГИИС ДМДК и произвести отправку
данных на регистрацию изделия в ГИИС и получение Уникального идентификатора для
изделия (UUID). Запрос необходимо подписать электронной подписью участника
обмена. Данные по запросу записываются в регистр сведений Запросы на
регистрацию изделия в ГИИС ДМДК. Далее необходимо выполнить
новый запрос 2. Получить результат запроса на регистрацию изделия в ГИИС
ДМДК и на основе данных с регистра
сведений Запросы на регистрацию изделия в ГИИС ДМДК в системе ГИИС ДМДК
создаются партии для каждого изделия с регистрацией ИНП/УИН, которые
загружаются обратно в систему «1С:Ломбард».
