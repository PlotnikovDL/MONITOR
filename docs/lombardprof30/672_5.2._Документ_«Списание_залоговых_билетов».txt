# 5.2. Документ «Списание залоговых билетов»



Операция списания залоговых билетов осуществляется
с использованием документа Списание бланков,
который располагается в разделе программы «1С:Ломбард».






Заполнение документа выполняется по следующим
реквизитам:



● Организация — организация, из которой будут списываться
бланки;



● Склад — склад, с которого будут списываться бланки;



● Подразделение — подразделение, с которого будут списываться
бланки;



● Вид операции — принимает значение Списание;



● закладка Бланки — содержит табличную часть, в которую вводится информация о списываемых
залоговых билетах.






Залоговые билеты вводятся по диапазонам
номеров. В колонке таблицы Бланки указывается название/вид бланка,
в колонке Серия — серия залоговых билетов. В колонке Начало
диапазона указывается первый номер залогового билета в диапазоне, а
в колонке Конец диапазона указывается последний номер залогового билета
в диапазоне. Если списывается один залоговый билет, его номер указывается, и в начале,
и в конце диапазона. Колонка Количество не редактируется, она необходима
для контроля количества списываемых залоговых билетов. В колонке Причина
списания указывается причина, по которой списывается залоговый билет.



При необходимости залоговые билеты можно
подобрать по кнопке Подбор.






При подборе имеется возможность быстрого
поиска залогового билета по серии и номеру. В поле Найти (серия) указывается
серия (или часть серии), которую необходимо найти. В поле Найти (номер) указывается
номер (или часть номера), который нужно найти.






При проведении документа в регистр Состояния
бланков записывается информация по номерам залоговых билетов со статусом
Списан.






В описанном документе при его записи и
проведении, а также по кнопке Проверить осуществляется контроль на
возможность списания залоговых билетов.



Установлены следующие критерии контроля
проверки:



● при списании проверяется, был ли ранее отражен залоговый
билет в системе;



● списываемый залоговый билет должен числиться в подразделении,
которое указано в документе;



● списываемый залоговый билет должен числиться на складе,
который указан в документе.






В результате проверки отображается отчет
с таблицей по тем бланками, которые не подходят для списания. Бланки выводятся по
номерам, подразделениям, складам и их текущим состояниям.



Красным выделяются бланки, которые не
прошли проверку, а также данные, которые не подходят по критериям списания.






Для проведения операции списания залоговые
билеты должны обладать требуемым статусом. Текущий статус должен быть установлен
как Списан.
Ошибочно могут списываться залоговые билеты со статусом Принят, или когда залоговые
билеты числятся на другом подразделении, например бланки находятся в подразделении
«Ломбард1»,
а в документе ошибочно указано, что они списываются по «Основное подразделение».
