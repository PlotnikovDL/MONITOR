# 6.4.3. Быстрый частичный перезалог с возвратом одного из изделий (в рамках перезалога)



Документ Перезалог также предназначен для изменения условий договора займа
(срока, схемы начисления процентов) и (или) с частичным выкупом залоговых
изделий в случаях, когда в обеспечение займа были получены два и более
залоговых изделия.



Документ может применяться в случаях,
когда в параметрах учета операций по займу и залогу функция Создание
договора при перезалоге не применяется и не используется.



Для создания
документа Быстрый частичный Перезалог необходимо в форме списка документов
в выпадающем списке по кнопке Перезалог выбрать команду Быстрый
частичный.






Выполнение
команды приводит к открытию специализированной формы Мастер создания
быстрого частичного перезалога с различными диалоговыми окнами. В
основном окне необходимо заполнить следующие поля:



● 
Договор;



● 
Заемщик;



● 
Залоговый билет;



● 
Срок выдачи займа;



● 
Дата окончания;



● 
Дата окончания
льготного срока;






После
заполнения по кнопке Далее
открывается следующее окно выбора и заполнения данных по номенклатуре с двумя
табличными списками по предметам, остающимся в залоге, и по выкупаемым
предметам.






В таблице Предметы, остающиеся в залоге следует выбрать одно или несколько изделий,
которые подлежат выкупу. Далее по команде Перенести выбранные выделенные
предметы залога перемещаются в таблицу Выкупаемые предметы.






В таблице формы документа Выкупаемые
предметы указываются только те предметы, которые выкупаются клиентом. Допускается
возврат из таблицы в список предметов, остающихся в залоге, используя команду
по кнопке Отменить выбранные.



Когда выбор закончен, выполняется следующая
команда по кнопке Оформить, после чего формируется новый документ
залога, но уже с теми предметами, которые остались в залоге.





Важно! Старый залоговый билет после оформления документа
закрывается.






Из формы Мастер создания быстрого
частичного перезалога так же предоставляется возможность распечатать
комплект документов, используя соответствующую команду.
