# 4.5.1. Документ «Закрытие парных счетов»



В соответствии с Положением Банка России
№ 803-П закрытие парных счетов производится по лицевым счетам.



Если на лицевом счете образуется сальдо
(остаток), противоположное признаку счета (на пассивном счете — дебетовое или на
активном — кредитовое), то оно должно быть перенесено бухгалтерской записью на соответствующий
парный лицевой счет по учету средств.



Если по каким-либо причинам образовалось
сальдо (остатки) на обоих парных лицевых счетах, необходимо перечислить бухгалтерской
записью меньшее сальдо на счет с большим сальдо, то есть в итоге должно остаться
только одно сальдо — либо дебетовое, либо кредитовое на одном из парных лицевых
счетов.



Выполнение требований положений Банка
России обеспечивается документом Закрытие
парных счетов.









Для закрытия парных счетов необходимо
заполнить следующие поля:



● Организация — указывается организация, для которой выполняется
закрытие парных счетов;



● Тип закрытия — имеет несколько предопределенных значений,
где в основное закрытие входит закрытие парных счетов, содержащихся в регистре Парные
счета в разделе программы Администрирование и настройка НФО, а также закрытие счетов,
не являющихся парными;






● Содержание – поле содержит краткое описание
выполняемых действий;



● Ограничения по счетам — ссылка открывает панель с
табличной частью, которая используется для закрытия конкретной пары счетов;






При задании ограничений по счетам в
табличной части по команде Заполнить счета из регистра Парные счета в документ будут загружаться
только парные счета и по тем счетам, напротив которых установлена отметка Использовать, будет происходить закрытие.
Если парных счетов, по которым необходимо сделать закрытие, немного, по кнопке Добавить можно внести новые и дополнить
список необходимыми счетами, после чего следует провести документ.
