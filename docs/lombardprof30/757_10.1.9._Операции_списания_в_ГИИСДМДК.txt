# 10.1.9. Операции списания в ГИИСДМДК



На основе документа возврат можно отправить
информацию по изделиям в ГИИС. После успешной регистрации изделия перейдут в Архив
в ГИИС ДМДК.






Выполнение Операции по списанию
изделий производится в следующем порядке:



1. По кнопке 1. Зарегистрировать
запрос на списание в ГИИС ДМДК регистрируется Уникальный идентификатор
запроса (UUID) на списание изделия. Запрос в ГИИС ДМДК необходимо подписать
электронной подписью. Данные по запросу записываются в регистр сведений Запросы
на регистрацию изделия в ГИИС ДМДК.



2. По кнопке 2. Получить результат
списания c ГИИС ДМДК на основе данных из регистра сведений Запросы на
регистрацию изделия в ГИИС ДМДК в ГИИС ДМДК создаются записи на списание
для каждого изделия с регистрацией ИНП/УИН. Для получения результатов списания запрос
необходимо подписать электронной подписью.
