# 6.1.4. Объекты учета ювелирных изделий




## Учет номенклатурных позиций по металлам



Для учета номенклатурных позиций по
драгметаллам используется справочник Металлы,
т.е. для тех номенклатурных
позиций и товаров у которых установлен тип изделия как Ювелирное
изделие. В первую очередь
справочник предназначен для последующего учета металлов и проб у ювелирных
изделий.



Обратиться к справочнику можно путем выбора
ссылки Металлы на панели разделов программы Ломбард: Настройки — Оценка металлов.



Подробней о справочнике Металлы
изложено в разделе руководства Справочник
«Металлы».




## Учет номенклатурных позиций по вставкам



Вставка (ювелирная вставка) — элемент ювелирного изделия из драгоценных,
полудрагоценных, поделочных, цветных камней и других материалов природного или искусственного
происхождения.



В конфигурации «Ломбард» для ювелирных
изделий предусмотрена возможность детализированного учета вставок. Если в форме
элемента номенклатуры активен параметр Вставки ГИИС ДМДК, то в
форме также отображается табличная часть для заполнения характеристик по имеющимся
вставкам в изделии, в том числе с указанием количества и веса этих вставок.






В общем случае вставки уменьшают вес металла
в изделии, тем самым уменьшая стоимость оценки, но в некоторых случаях вставки могут
иметь собственную ценность и увеличивать стоимость предмета залога и выдаваемую
сумму займа.




## Справочники для заполнения вставок в предметах залога



Для заполнения характеристик вставок в
предметах залога реализованы справочники:



● Виды драгоценных камней;



● Качество ДК;



● Формы огранки ДК;



● Цвета ДК.



Обратиться к справочникам можно путем
выбора той или иной ссылки в панели разделов программы Ломбард: Настройки — Оценка вставок ювелирных изделий.






Если справочники
не заполнены, то требуется открыть и заполнить его стандартными значениями
согласно требованиям государственной системы ГИИС ДМДК.



В каждом справочнике характеристик
вставок на форме списка добавлена команда Заполнить значения справочника.
Команда позволяет произвести заполнение справочника значениями, которые
определены регулятором государственной системы.






В справочнике доступна возможность
самостоятельного заполнения сокращенного наименования для каждого элемента
справочника, которое участвует при заполнении полного наименования изделия.



В связи с требованиями обмена данными
с ГИИС ДМДК не допустимо изменять значения реквизитов элементов справочника.



Для того, чтобы приступить к
заполнению характеристик по вставкам, в форме номенклатуры необходимо
установить отметку у параметра Вставки ГИИС ДМДК, выполнить запись
элемента и далее выполнить ввод данных части характеристик по имеющимся
вставкам в изделии, в том числе с указанием количества и веса вставок на
основной форме справочника. Далее в табличной части Вставки необходимо
заполнить детализированное описание вставок и заполнить информацию по элементам
вставок:



● Тип вставки ГИИС;



● Вид вставки;



● Описание прочих вставок;



● Цвета ДК;






● Качество ДК;



● Форма огранки ДК;



● Вес за шт.;



● Штук;



● Оценка;



● Сумма займа.





Важно! Из указанных характеристик такие поля как Описание прочих
вставок, Оценка и Сумма займа не являются обязательными для
заполнения.






Дополнительные сведения по учету
информации по вставкам приводятся в разделе руководства Рабочее
место товароведа: операция по вставкам ГИИС ДМДК.
