# 2.2.3. Отбор проводок (Фильтр)



Справочник Отбор проводок предназначен для
хранения критериев фильтрации данных при определении лицевого счета (значения
для поля Фильтр, описанного ранее в разделе руководства Правила
определения лицевых счетов и их номеров).



Открытие
справочника выполняется из панели разделов программы Администрирование и
настройка НФО выбором команды Отбор проводок (группа Настройка
трансляции и формирования лицевых счетов).






В
форме элемента справочника Отбор
проводок задается следующая информация:






● 
Наименование —
наименование фильтра (отбора) определяет уникальность записи (элемента
справочника) с настроенными параметрами отбора;



● 
Отбор —
указываются поля из записи хозяйственных операций, вид отбора и значение для
отбора и условия для формирования отбора



Перечень
параметров, по которым возможно осуществление отбора проводок:



● 
субконто (имеется
в виду субконто счета РСБУ, который транслируется);



● 
корр. субконто
(имеется в виду субконто корр. счета транслируемого счета РСБУ);



● 
валюте проводки
РСБУ (как со стороны транслируемого счета, так и со стороны корр. счета);



● 
сумме проводки
РСБУ;



● 
номеру строки
(номер проводки, если документ делает несколько проводок);



● 
организации;



● 
транслируемому
счету РСБУ и его корр. счету.



Существует
возможность сгруппировать условия. Операция по группировке выполняется
пользователем по необходимости самостоятельно.
