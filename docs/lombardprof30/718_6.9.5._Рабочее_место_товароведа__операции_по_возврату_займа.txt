# 6.9.5. Рабочее место товароведа: операции по возврату займа



При создании возврата займа по действующему
договору для того, чтобы не заполнять заново реквизиты документа Возврат займа
в части физического лица — заемщика и договора, необходимо перед созданием операции
в окне Рабочее место товароведа сформировать отбор, соответствующий искомому
заемщику и договору.



В случае попытки создания документа Возврат
займа без предварительного отбора по физическому лицу, будет выведено сообщение
«Не задан отбор по залогодателю».









В форме документа Возврат займа
заполняются и проверяются следующие поля:



● Значения полей Организация, Склад, Подразделение –
поля могут быть предварительно заполнены при условии наличия настроенных
параметров по ограничению прав для пользователя, выполняющего текущую операцию;



● Сумма погашения (всего) — значение рассчитывается
автоматически и заполняется суммой основного долга и процентов, начисленных на
дату оформления документа Возврат займа;



● Погашен займ — реквизит автоматически заполняется
значением суммы, равной остатку задолженности по основному долгу займа на дату
документа Возврат займа.



После заполнения и проверки реквизитов
документа выполняется команда Провести. Также после записи и проведения
документа можно:



● по команде Печать вывести печатную форму документа
«Акт приема-передачи имущества»;



● создать на основании кассовый документ по выдаче наличных
или документ Операция по платежной карте.



При создании новых документов через
механизм «на основании» их заполнение происходит автоматически по данным
документа-основания, достаточно проверить корректность заполнения и выполнить затем
одну из команд Провести или Провести и закрыть. Печать
чека производится командой по кнопке Чек при наличии подключенного
специализированного оборудования печати чеков.
