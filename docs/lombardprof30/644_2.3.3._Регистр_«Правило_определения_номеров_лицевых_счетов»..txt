# 2.3.3. Регистр «Правило определения номеров лицевых счетов».



Регистр служит для заполнения правил формирования
номера лицевого счета.






Если в списке правил само правило не
определено, создать его можно сразу в регистре двойным нажатием на левую кнопку






В открывшейся форме необходимо заполнить
следующие данные:



● Указать правила для определения кода валюты и кода доверительного
управления (15 символов) — отметка устанавливается при необходимости изменить код
валюты или код доверительного управления и заполнить 15 знаков вместо 11;



● Количество разрядов — указывается количество знаков, которые
будут использоваться в лицевом счете (без отметки сумма по столбцу должна составлять
11, с установленным флажком — 15 знаков); 



● Источник — заполняется вид поля, по которому будут определяться
символы лицевого счета:



- 
Фиксированное
значение при указании источника означает,
что в лицевой счет будет попадать определенный набор цифр;



- 
виды полей Организация
и Подразделение означают, что в лицевой счет будет попадать одно из свойств
организации или подразделения (например: код, ИНН, КПП и т.п.);



● Вид субконто — данные для формирования лицевого счета будут
взяты из аналитических разрезов счета по РСБУ, при условии, что Источник содержит
значение Из субконто (при заполнении этого вида необходимо выбрать вид субконто,
из которого будут формироваться данные для определения счёта);



● Правило определения кода — выбирается одно из свойств субконто,
которое описывает числовое значение, например: код, ИНН, ОКПО и т.д.
