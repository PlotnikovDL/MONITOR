# 6.1.5. Классификатор предметов залога и хранения




## Классификатор предметов залога и хранения



Классификатор по
предметам залога предназначен для хранения информации о единицах хранения –
объектах залогового имущества






Для введения нового элемента классификатора предмета залога и хранения,
требуется ввести новый элемент командой по кнопке Создать или
скопировать из предыдущего однородного элемента, используя команл по кнопке с
изображением Скопировать.






При заполнении
следует обратить внимание на следующие поля:









● Наименование — указывается названия классификатора;



● Тип изделия — предопределенный справочник с заданными типами
изделий («ювелирное», «автомобиль», «мех», «прочее»);



● Группа — указывается группа, в которую входит классификатор
Состояние изделия.




## Классификатор «Состояние изделия»



Классификатор содержит сведения о
состоянии изделия:






● Наименование — указывается полное наименование состояния
(«новое», «использованное»);



● Краткое описание — указывается короткое наименование состояния
(«новый» или «б/у»)
