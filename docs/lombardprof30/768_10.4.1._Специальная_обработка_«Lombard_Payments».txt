# 10.4.1. Специальная обработка «Lombard Payments»



Форма специальной обработки предназначена для предоставления
сервисной информации «Lombard Payments» и включает в себя следующие закладки:



● Транзакции — отображает транзакции, зарегистрированные
в сервисе (на форме также доступны отборы по периоду и типу транзакции.



● Уведомления — отображает уведомления пользователю, сформированные
сервисом Lombard Payments.



● Документы — отображает перечень сформированных документов
(в списке доступна команда скачивания).






В решении
«1С:Ломбард» предусмотрена также работа с сервисом «Lombard Payments» из документа
Выдача займа. При вызове команды по
кнопке Lombard Tech открывается встроенное меню с
основными операциями:






● Настроить доступ — выполняется вход в личный кабинет
заемщика с авторизацией входа;



● Выплата на карту — используется для случаев, когда сумма
займа переводится на банковскую карту заемщика;



● Создать карту «Богатство» — создание новой карты для
пользования услугами Lombard
Tech.



Операция Выплата на карту
может осуществляться на карту клиента любого банка, а также на карту «Богатство».






При
создании карты в списке карт нужно выполнить команду по кнопке Создать. Для ввода сведений откроется форма
ввода данных.
