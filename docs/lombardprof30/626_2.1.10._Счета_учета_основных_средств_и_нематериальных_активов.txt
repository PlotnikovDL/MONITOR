# 2.1.10. Счета учета основных средств и нематериальных активов



Для ввода новой записи необходимо использовать
команду Создать. В открывшейся
форме заполнить следующие данные:



● Тип необоротного актива (обязательное к заполнению поле)
— тип внеоборотного актива, используемый при принятии к учету (ОС или НМА) или заполнении
остатков;



● Организация — указывается организация, для которой выполняются
настройки параметров счетов учета (при отсутствии значения указанный счет учета
будет использоваться в учете для всех организаций);



● Объект — указывается объект учета (ОС или НМА), для которого
выполняются данные настройки, если значение не выбрано, то счет учета будет использоваться
для всех объектов учета выбранного типа и организации;



● Счета учета и статьи доходов/расходов — задаются из плана
счетов пользователем в соответствии с выбранным типом необоротного актива.
