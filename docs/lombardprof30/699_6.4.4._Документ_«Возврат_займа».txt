# 6.4.4. Документ «Возврат займа»



Документ по возврату займов используется
для оформления прекращения обязательств по договору займа и возврату залогового
имущества залогодателю. Конфигурация решения позволяет создать документ по
возврату из уже записанного ранее в систему документа Выдача займа, получение залога.






Кроме этого, пользователь имеет
возможность перейти в список документов, сам переход выполняется по ссылке Возврат
займа из панели разделов Ломбард
— Займы и залоги.






В создаваемом документе Возврат займа, выполненном на основании
документа (из документа) Выдача займа, получение
залога, все поля заполняются автоматически по данным из документа основания.






После проведения документа формируются
проводки по списанию залогового имущества и по доначислению процентов. При
варианте учета по РСБУ проводки формируются в соответствии с правилами учета
для большинства организаций.






При учете по отраслевым стандартам
Банка России проводки формируются по счетам учета ЕПС.






Конфигурация «Ломбард» позволяет сформировать
документ Поступление наличных с использованием механизм «ввода на основании»
из документа Возврат займа. Для
этого в документе возврата выполняется выбор соответствующего пункта из встроенного
меню по кнопке Создать на основании.
