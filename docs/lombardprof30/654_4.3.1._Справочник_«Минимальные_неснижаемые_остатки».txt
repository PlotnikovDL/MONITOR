# 4.3.1. Справочник «Минимальные неснижаемые остатки»



Минимальный неснижаемый остаток (МНО)
— это остаток на счете, который должен
быть не ниже определенной суммы в заданной валюте в течение заданного периода времени.



Для определения неснижаемого остатка по
счету в системе используется справочник Минимальные
неснижаемые остатки.






При вводе нового элемента в
справочник необходимо заполнить соответствующие поля:



● Дата возникновения остатка — дата, с которой нельзя иметь
на счету сумму, меньшей указанной на форме,



● Банковский счет — указывается счет, на котором будет неснижаемый
остаток,



● Ставка начисления по отношению к неснижаемому остатку,



● Сумма — величина минимального неснижаемого остатка.



Справочник используется для задания параметров
депозитов.
