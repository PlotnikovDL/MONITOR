# 2.1.14. Категория клиентов



Справочник Категории клиентов предназначен
для хранения дополнительной информации о категориях клиентов ломбарда. Справочник
находится анкете физического лица, на закладке Клиент ломбарда.






Справочник содержит предопределённое
значение Новый заемщик и позволяет внести в него новые виды
категорий или внести изменения в существующие.






При создании новой записи по команде Создать
откроется форма ввода, где нужно внести Наименование. Значение в поле Код
заполнится автоматически после записи нового элемента в справочник. Код – системный номер справочника.
