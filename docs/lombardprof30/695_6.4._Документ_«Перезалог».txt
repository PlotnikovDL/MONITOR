# 6.4. Документ «Перезалог»



Документ Перезалог необходим для
изменения условий договора займа (срока, схемы начисления процентов и др.). Открыть
список документов можно путем выбора на панели разделов Ломбард — Займы и залоги ссылки Перезалог.









Создание новых документов выполняется
по команде Перезалог и выполняется для разных случаев.
