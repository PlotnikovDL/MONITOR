# 2.1.13. Параметры учета операций по займам и залогам



Для ввода
новой записи необходимо выполнить команду Создать,
после чего откроется форма Параметры
учета операций по займу и залогу.






В открывшейся форме Параметры учета операций по
займу и залогу (создание) необходимо
заполнить следующие данные:






● 
Организация —
указывается организация, для которой выполняется настройка параметров учета;



● 
Применяется с —
устанавливается период начала применения задаваемых параметров учета;



● 
Автоматическое
начисление процентов — устанавливается признак для автоматического начисления
процентов при выполнении служебного регламентного задания;



● 
Автоматический
подбор бланка – когда отметка установлена, то обеспечивается выполнение функции
автоматического подбора бланка в документах выдачи займа и перезалога. Для
этого, Пользователю необходимо установить свои настройки параметров подбора
бланка.



Форма
настройки учетной политики Параметры
учета операций по займу и залогу (создание)
содержит четыре вкладки для заполнения параметров учета:



● 
Заем и Залог;



● 
Хранение;



● 
Реализация и
изъятие;



● 
Общее.






Вкладка Заем и залог содержит поля для выбора
значений (на скриншоте ниже общий
вид вкладки Заем и залог):






Поле Приоритет в условиях займа — значение устанавливается Пользователем из
контекстного меню, на выбор, в зависимости от того, что первично:



- 
Условия займа
определяют срок и сумму займа;



- 
Сумма и срок определяют
доступные условия займа;






● 
Залоговый билет,
вид бланка — указывается вид бланка, значение которого будет подставляться в
документ Выдача займа;






● 
Вид бланка выбирается
из 2 типов данных (Бланки строгой отчетности или Номенклатура);






● 
Залоговый билет,
счет учета — поле отображается при применении режима учета операций в системе Трансляция,
в качестве значения необходимо задать соответствующий счет учета залогового
билета в учете по РСБУ;



● 
Тип залоговых
изделий по умолчанию – значение в поле заполняется путем подбора значения из
контекстного меню для выбора по умолчанию типа залогового изделия






● 
В подразделе Параметры расчета
заполняются поля для определения временных границ и порядка расчета займа. Для
установки значений нужно заполнить поля:



● 
Заем, начисление
для границ периода: — поле для установки значения первого дня, с которого
начинают исчисляться проценты по договору






● 
Заем, начисление
за день перезалога: — поле для выбора значения, будет ли участвовать в расчете
процентов день перезалога;






Заем, начисление при изменении условий: — поле для
выбора условий расчета процентов при изменении условий займа.






Расчет дней займа: — поле для
выбора условий расчета процентов при изменении условий займа.









● 
В подразделе
Cчета учета займа и залога заполняются следующие поля:






● 
Предметы залога,
счет учета — поле отображается при применении режима учета Трансляция,
необходимо задать соответствующий счет учета залогового имущества по РСБУ;



● 
Займ, счет учета
— поле отображается при применении режима учета Трансляция, задается счет учета займа по РСБУ;



● 
Займ, счет учета
процентов — поле отображается при применении режима учета Трансляция,
задается счет учета процентов по займу по РСБУ;



● 
Вид оплаты для
платежных карт: — поле заполняется Пользователем при выборе способа оплаты по
каждому договору индивидуально. Список дополняется пользователем по кнопке Создать
в зависимости от способа оплаты.









Для
договора займа могут быть созданы печатные формы документов:



Печать
залогового билета с документов залога;



Печать
исходного залогового билета;



Печать
исходных индивидуальных условий;



Создание
договора при перезалоге;



Создание
и печать платежных документов по договорам займа






Для
получения необходимых печатных форм из списка, Пользователю требуется их
пометить, проставить соответствующие отметки в информационных полях.



Форму
залогового билета при выдаче и возврате займа, Пользователь может выбрать из
контекстного меню.






Вкладка Хранение используется для настройки параметров
и задания вида документа для хранения залоговых вещей:



● 
Сохранная
квитанция, вид бланка — поле для выбора одного из предопределенных видов
документа: «сохранной квитанции» или залогового билета из справочника Бланки
строгой отчетности или конкретного объекта из справочника Номенклатура;









Сохранная квитанция, счет учета: — поле
отображается при применении режима учета Трансляция, в качестве
значения задается счет учета займа по РСБУ;



Вещи на хранении, счет учета: — поле
отображается при применении режима учета Трансляция, задается
счет учета вещей на хранении по РСБУ;






Вкладка
Хранение содержит информационные поля для фиксирования условий хранения
вещей для определения границ периода хранения и начисления платы за
хранение при изменении условий.






Выбор
вышеуказанных параметров осуществляется Пользователем через контекстное меню из
предопределенных значений системы









С помощью параметров и реквизитов на вкладке Реализация и
изъятие производится настройка счетов учета:



● 
Расчеты
с заемщиком;



● 
Счета
расчетов при изъятии;



● 
Счет
для учета прибыли по реализации;



● 
Счет
доходов и расходов;



● 
Счет
учета резерва под обесценение.



Выбор счетов производится Пользователем из плана счетов
бухгалтерского учета по РСБУ или по ЕПC.






Так же необходимо указать, выбрав из контекстного меню,
статью Дохода и Расхода, и Статью расходов (разница оценки предметов и выручки)



Дополнительно, с помощью проставления галочки необходимо указать производить или нет зачет
обязательств между покупателем и заемщиком в документе Реализация залогового
имущества и нужно ли принимать к НУ задолженность заемщика списанную за
счет резерва под обесценение.



Вкладка
Общее содержит возможность производить округления сумм самого займа,
либо суммы начисляемых процентов, либо дневной ставки.






Вариант округления выбирается из
контекстного меню при установленной отметке Использовать.






Точность округления устанавливается
Пользователем в одноименном информационном поле (с двумя знаков после запятой).






Во вкладке Общее дополнительно можно установить по
умолчанию счет кассы (из Плана счетов РСБУ или ЕПС), а так же указать из
справочника Номенклатура, услугу по страхованию предмета залога.
