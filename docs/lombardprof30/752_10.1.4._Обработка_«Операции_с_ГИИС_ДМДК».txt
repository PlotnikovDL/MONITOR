# 10.1.4. Обработка «Операции с ГИИС ДМДК»



Обработка Операции С ГИИС ДМДК
предназначена для интеграции и обмена данными с ГИИС ДМДК. Возможности
обработки позволяют:



● присвоить уникальный идентификатор (УИН) изделиям на
основе введенных партии в ГИИС и в систему «1С:Ломбард» с идентификационный
номер партии (ИНП);



● присвоить ИНП партиям;



● присвоить УИН изделиям;



● списать изделия, по которым был возврат.



Открытие обработки
выполняется из панели разделов Ломбард:Настройка – ГИИС ДМДК по ссылке Операции
с ГИИС ДМДК.



Для проверки подключения обмена можно
воспользоваться командой Проверить подключение в шапке обработки:






Для быстрого формировании документов
в шапке формы обработки есть поля ввода:



● Организация – по умолчанию используется
значение из справочника Организации, само значение определяется тем как она,
вводится в поле Организация полученного сертификата на подключение;



● Адрес подключения — адрес для подключения к личному
кабинету ГИИС ДМДК, указанный при настройке подключения (если
личный/обезличенный сертификат и решение 1С находятся в одном компьютере, адрес
— 127.0.0.1:1500).



● Версия сервиса — указывается версия контура ГИИС ДМДК
по которому выполняется обмен данными.
