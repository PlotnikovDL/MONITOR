# 6.1.3. Присоединенные файлы



Для более детального описания изделия
или его частей можно использовать дополнительные изображения и документы в виде
дополнительных файлов, прикладываемых к предмету залога.



Для того, чтобы включить в описание изделия
дополнительную информацию, необходимо в разделе Общие сведения для залога выбрать и выполнить команду по кнопке Файл.






Используя команду Добавить и необходимо выбрать команду
Файл с диска, загрузить фотографию
либо иной документ описываемого имущества в базу.






Любой из добавленных файлов изображений
может быть установлен в качестве основного изображения для предмета залога.
