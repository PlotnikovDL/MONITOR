# 4.5.3. Документ «Списание РБП»



Списание расходов будущих периодов (РБП),
затрат, произведенных организацией в предшествующем и/или отчетном периодах, но
подлежащих включению в себестоимость в последующие периоды деятельности организации,
происходит через выполнение регламентной операции Списание РБП. Обратиться к документу, в котором регистрируется данная
операция можно путем выбора на панели разделов программы Учет НФО — Регламентные операции
НФО по ссылке Списание РБП.






При создании документа Списание РБП
на форме документа необходимо заполнить следующие реквизиты:



● Период — период, за который проводится расчет по
списанию РБП;



● Организация — указывается организация, для которой проводится
регламентная операция;



● Состояние — указывается результат выполнения регламентной
операции, значение заполняется автоматически;



● Комментарий — заполняется в произвольной форме;



● Ответственный — устанавливается пользователь, выполняющий
регламентную операцию, значение заполняется автоматически.
