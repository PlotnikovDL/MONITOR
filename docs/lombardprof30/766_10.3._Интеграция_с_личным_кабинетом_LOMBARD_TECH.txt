# 10.3. Интеграция с личным кабинетом LOMBARD TECH



Мультиплатформенная
система Lombard Tech является
универсальной системой обработки
финансовой информации, позволяющей выполнять все необходимые операции клиентам
и ломбардам, сокращать время выплаты займов во всех отделениях ломбарда, проводить
выплаты с единого счета в Банке-партнере, контролировать расходы в реальном
времени, просматривать статистику с любого устройства, имеющего доступ в
интернет. Для подключения к этой системе и организации взаимодействия следует
выполнить установку параметров работы через раздел программы Ломбард:Настройки
– Интеграция – Lombard Tech.






Интеграция с личным кабинетом организации в
сервисе Lombard Tech служит для возможности приема и
передачи информации клиентам и от клиентов ломбарду, позволяет выгружать информацию
по залоговым билетам или сохранным квитанциям в личный кабинет клиента,
проводить оплаты и выдачу займов и процентов.



Для работы следует настроить параметры
подключения и параметры расписаний для выполнения тех или иных задач обмена
данным.






По ссылке Настроить
расписание можно установить график выполнения операций:









На закладке Общее указываются дата начала и завершения задания и режим повтора.



На закладке
Дневное устанавливаются параметры
для ежедневного выполнения задания.



● По кнопке Укажите расписание устанавливется:



● Астрономическое время начала и время окончания задания;



● Астрономическое время завершения задания, после которого
выполнение задания не требуется;



● Интервал повторения задания;



● Размер паузы между повторами;



● Продолжительность выполнения.



Допускается
указание произвольного сочетания условий.



На закладке
Недельное устанавливаются параметры
для еженедельного выполнения задания.



При задании параметров требуется установить отметки по
тем дням недели, в которых задание будет выполняться. Если требуется повторять задание, указывается интервал
повтора в неделях. Например, задание выполняется через две недели, значение повтора
устанавливается равным «2».



На закладке
Месячное устанавливаются параметры
выполнения задания каждый календарный месяц. При задании параметров требуется
установить отметки по тем месяцам, в которых
задание будет выполняться. При необходимости можно
указать конкретный день (месяца или недели) выполнения с начала месяца / недели
или конца.
