# 3.1. Ввод начальных остатков



Ввод начальных остатков выполняется через
документ Ввод начальных остатков (займы,
хранение). Документ используется для ввода данных по контрагентам и выданным
займам, находящемуся на хранении залоговому имуществу.



Обратиться к списку документов можно путем
выбора из панели разделов Ломбард — Ввод начальных остатков по ссылке Ввод начальных остатков (займы,
хранение).









Для отражения операции ввода начальных
остатков необходимо заполнить основные реквизиты документа и внести данные по контрагенту.
Основные реквизиты документа:



● Номер — порядковый номер документа, значение
устанавливается автоматически;



● От — дата ввода остатков;



● Вид операции — ввод остатков выполняется либо на предоставление
займа, либо как прием на хранение;



● Выбор контрагентов, договоров — значение определяет, будут
ли контрагент и договор контрагента указываться вручную, либо определяться (создаваться)
автоматически;



● Организация — залогодержатель;



● Склад — место (склад) хранения залога;



● Подразделение — подразделение организации, где будут отражаться
операции оприходования залога.



Данные по контрагентам заполняются в специальном
окне редактирования.






Реквизиты для заполнения данных по контрагентам:



● Клиент — залогодатель, физическое лицо;



● Контрагент — залогодатель, контрагент;



● Договор контрагента — договора контрагента (залогодателя);



● Вид бланка — вид бланка залогового билета;



● Серия — серия залогового билета;



● Номер — номер залогового билета;



● Дата предоставления — дата предоставления займа;



● Срок (дней) — срок предоставления займа;



● Дата погашения — дата погашения займа;



● Льготный период до — дата истечения льготного периода;



● Тип изделий — тип изделия (перечисление);



● Табличная часть «Предметы залога» — содержит информацию
о предметах залога (номенклатура, ед. изм., количество и т.д.)



● Условия займа (схема расчета) — условия займа и хранения;



● Табличная часть «Условия займа» — содержит информацию
об условиях займа (вид начисления (номенклатура), формула расчета, ставка и
т.д.).



Окно редактирования данных контрагентов
содержит функциональность по автоматическому расчету стоимости предметов и
автоматическому расчету условий по параметрам договора (см. соответствующие
кнопки табличных частей).





Важно! При записи строки данных контрагента, при выбранном
режиме настройки выбора контрагентов (договоров) как Автоматическое определение (создание) происходит
автоматическое создание новых записей по контрагенту и договору с контрагентом.






При записи и проведении документа Ввод начальных остатков (займы, хранение)
выполняется запись хозяйственных операций на счетах учета (по РСБУ и по ЕПС — в
режиме Трансляция или только по ЕПС — в режиме Прямой учет).









Кроме этого, в процессе ввода
остатков выполняется запись данных в других регистрах для последующего ведения
учета:



● Учет предоставленных займов;



● Учет начислений по займам



● ПСК по договорам займа;



● Состояние залогового билета;



● Состояния бланков;



● Условия предоставленных займов.



Для удобства заполнения документов ввода
начальных остатков реализована функциональность загрузки остатков из файлов электронных
таблиц с расширением *.xls (*.xlsx).
