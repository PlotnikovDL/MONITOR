# 9.1. Проверка контрагентов по требованиям 115–ФЗ (ПОД/ФТ)



Для выполнения требований Федерального
закона «О противодействии легализации (отмыванию) доходов, полученных преступным
путем, и финансированию терроризма» № 115-ФЗ от 07.08.2001 в решении «1С:Ломбард»
предусмотрена возможность проведения сверки контрагентов по спискам, формируемым
Федеральным агентством Росфинмониторинг и в соответствии с внутренними документами
ломбардов.



Для того, чтобы обратиться к проверке
необходимо включить специальный режим блоке настройки функциональности решения.
Для этого следует перейти в пункт меню Администрирования
— Дополнительная функциональность НФО и обратиться к закладке НФО. На закладке в группе Проверка клиентов установить соответствующие признаки для проверки.






После установки признаков появится отельный
раздел программы Проверка клиентов 115-ФЗ и пр., с объектами обработки
данных для выполнения проверок.
