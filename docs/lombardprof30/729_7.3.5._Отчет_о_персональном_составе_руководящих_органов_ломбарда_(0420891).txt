# 7.3.5. Отчет о персональном составе руководящих органов ломбарда (0420891)



Отчет о персональном составе руководящих
органов ломбарда размещен в Комплекте отчетности в группе Форм отчетности в порядке надзора.






Для выбранного макета отчетной формы и установленным значением в поле Организация по кнопке Создать открывается форма
отчета для заполнения.









Процесс заполнения автоматический, по данным системы и при нажатии кнопки Заполнить.
