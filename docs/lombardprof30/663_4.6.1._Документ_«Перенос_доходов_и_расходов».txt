# 4.6.1. Документ «Перенос доходов и расходов»



Для реформации баланса по окончании
финансового года, требуется обнулить счета Доходов и расходов для следующего
отчетного периода. Это делается с помощью документа Перенос доходов и
расходов. Создание и проведение этого документа осуществляется в первый
день нового года. Перенос информации по доходам и расходам по операциям года
выполняется на счета учета финансового результата прошлого периода, документом
выполняется закрытие 710-ых счетов на 720-ые.



Для выполнения операции достаточно
настроить соответствие счетов учета для переноса доходов и расходов (см. раздел
Настройка
счетов для расчета финансового результата (ОСБУ Банка России)
данного руководства).



Создание документа по переносу
осуществляется путем выбора на панели разделов Учет НФО — Закрытие года по
ссылке Перенос доходов и
расходов.






В форме документа обязательными для заполнения
являются следующие поля:



● Дата — устанавливается первый день нового года;



● Организация — организация, по которой выполняется
закрытие года.
