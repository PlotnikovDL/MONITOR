# 6.10. Документ «Авизо по займам (исходящее»





Важно! Данный
функционал доступен только в «1С:Ломбард» версии КОРП.






Документ предназначен для отражения операций по
передаче займа из подразделения в подразделение.



Обращение к документу выполнить можно
путем выбора ссылки Авизо по займам
(исходящее) на панели разделов программы Ломбард.






В документе для передающей стороны
заполняются реквизиты Склад, Подразделение, а для принимающей – Склад
новый, Подразделение новое.






Заполнение таблицы Данные по контрагентам
выполняется при обращении к кнопке Добавить, а далее заполняются обязательные
поля Контрагент и Договор контрагента, и рассчитывается стоимость
предметов.






Кроме этого, заполнение таблицы выполняется
командой по кнопке Заполнить и выбором из встроенного меню одного
из двух вариантов:



● По данным учета
— все действующие;



● Просроченными договорами — только у тех, у которых истек срок льготного периода.






После записи документа создается проводка
по регистрам бухгалтерского учета.
