# 4.2. Справочник «Виды вознаграждения работникам»



Справочник Виды вознаграждения работникам предназначен для перечисления видов вознаграждения
работникам. Значения справочника используются при осуществлении записи хозяйственных
операций по счетам 60305, 60306, 60349, 60350.






В качестве значений для поля Наименование указывается вид вознаграждения.
