# 4.4. Ручные операции, шаблоны ручных операций



Конфигурация «Ломбард»
предусматривает возможность отражения хозяйственных операций, введенных вручную.
Для этого необходимо обратиться к панели разделов программы Учет НФО — Документы и перейти по ссылке Ручные операции.






Для задания в открывшемся списке документов
Ручные операции (НФО) для ввода новой операции необходимо выполнить
команду Создать и выбрать значение
Операция (НФО).






В форме заполнения ручной операции заполняются
следующие значения:



● устанавливается Счет по дебету – для отражения
операций по дебетовой стороне счета;



● если на счете ведется учет по подразделениям, заполняется
в строке таблицы поле Подразделение;



● выбираются значения субконто по дебету указанного
счета дебета;



● устанавливается Счет по кредиту;



● если на счете ведется учет по подразделениям, заполняется
в строке таблицы поле Подразделение;



● выбираются значения субконто по кредиту счета;



● Сумма — заполняется значение суммы в бухгалтерском учете;



● Сумма Дт — заполняется сумма по дебету в налоговом учете;



● Сумма Кт — заполняется сумма по кредиту в налоговом учете.





Важно! Необходимо учитывать, что должно выполняться контрольное
соотношение при формировании проводок и ручных операций:



БУ = НУ +
ПР + ВР.






В конфигурации существует механизм создания
типовых ручных операций с помощью шаблона и применяемый в ситуации, когда имеются
проводки, часто создаваемые вручную, но для которых нет отдельного документа в конфигурации.



Запись типовой операции выполняется в
списке Ручнее операции и выбором пункта Типовые операции (НФО)
из встроенного меню по кнопке Создать. В списке Типовые операции используется
затем команда Создать.






Изначально формируется определенный
шаблон типовой операции. В форме типовой операции заполнение полей производится
таким же образом, как и при заполнении обычной ручной операции. Но заполняются
данными только те поля, которые для данного типа проводок постоянны и не
подразумевают изменения в дальнейшем.






В поле Содержание
описывается то, что будет делать операция, описанная создаваемым
шаблоном. Когда нужно будет по этому шаблону создать операцию откроется список
шаблонов и будут по этому содержанию отражаться операции в списке.



Каждая строка таблицы будет
автоматически создавать проводку бухгалтерского и налогового учета.



Если от операции к операции всегда
будет одно и то же значение параметра, который указан в таблице в угловых
скобках, удобней задать его значение сразу, чтобы не вводить каждый раз при
создании операции. Тогда программа при выборе варианта Значение
будет подставлять заданное значение при каждом новом оформлении документа Операция по этой типовой операции.






Если же значение какого-то параметра
заранее неизвестно, то используется значение Параметр. Тогда
необходимо будет указывать значение реквизита каждый раз при создании операции
по этому шаблону, например, выбирать контрагента, номенклатуру, физ.лицо или иное
значение.






На закладке Список параметров
перечислены параметры, которые используются в этой типовой операции и не имеют
заданных значений. Здесь можно добавить новый параметр, изменить существующий,
поменять последовательность параметров. Все сделанные изменения повлияют на
документ Операция.



Для того чтобы в шаблоне можно было
заполнять регистры сведений и накоплений по кнопке Еще из встроенного
меню по команде Выбор регистров выполняется выбор объектов для
заполнения. Когда регистры будут выбраны, программа создаст для каждого
регистра дополнительную закладку.





Важно! Для ввода параметров и выбора регистров следует
записать шаблон типовой операции.









После создания шаблона типовой
операции можно уже выбирать требуемый шаблон для дальнейшего заполнения ручной
операции, наполнить значениями список параметров и выполнить команду Заполнить,
в результате чего автоматически сформируется проводка.






Подробнее об использовании ручных операций и типовых изложено в разделе Прочие операции руководства
по ведению учета в решении «1С:Бухгалтерия 8».
