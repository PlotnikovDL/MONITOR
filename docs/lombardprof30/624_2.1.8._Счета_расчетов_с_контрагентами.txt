# 2.1.8. Счета расчетов с контрагентами



Для ввода новой записи необходимо использовать
команду Создать. В открывшейся
форме следует заполнить следующие данные:



● Организация — сведения о не кредитной финансовой организации
(НФО), для которой выполняется настройка. Если поле не заполнено, настройка действует
для всех организаций, учет деятельности которых ведется в информационной базе;



● Контрагент — сведения о контрагенте, для которого выполняется
настройка. Если поле не заполнено, настройка действует для всех контрагентов;



● Договор — сведения о договоре, для которого выполняется
настройка. Если поле не заполнено, настройка действует для всех договоров;



● Вид расчетов — выбирается вид расчета. Если поле не заполнено,
настройка действует для любого вида расчета. Возможные варианты: расчеты в валюте
регламентированного учета, в условных единица, в иностранной валюте.
