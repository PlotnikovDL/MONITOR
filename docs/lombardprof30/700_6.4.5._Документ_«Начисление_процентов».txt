# 6.4.5. Документ «Начисление процентов»



Документ по начислению процентов
используется для ежедневного или ежемесячного начисления процентов по договорам
займа в разрезе каждого договора займа.



Обратиться к документу можно путем
выбора из панели разделов программы Ломбард
— Регламентные операции соответствующей ссылки Начисление процентов. При переходе по ссылке открывается список
документов, при работе со списком включены команды по добавлению новых и
корректировке уже введенных документов.






Форма документа Начисление процентов содержит реквизиты, задающие период начисления
и организацию, от лица которой проводится операция.



Номер документа заполняется автоматически, пользователь
имеет возможность внести в поле Комментарий
дополнительную информацию. Информационная строка Состояние отражает результат проведения операции.






После проведения документа формируются
проводки по счетам учета РСБУ, а также ОСБУ.
