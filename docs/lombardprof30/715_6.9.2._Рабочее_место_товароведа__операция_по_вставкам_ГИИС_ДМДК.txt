# 6.9.2. Рабочее место товароведа: операция по вставкам ГИИС ДМДК



При оформлении документов с
номенклатурой в виде ювелирных изделий важно правильной учитывать «вставки». Для
заполнения характеристик по вставкам в ювелирном изделии необходимо установить
признак Вставки ГИИС ДМДК. После чего появится форма заполнения информации
по вставкам для последующей выгрузки сведений по вставкам в государственную
информационную систему по драгоценным металлам и драгоценным камням (ГИИС ДМДК).





Важно! Решением «1С:Ломбард» поддерживает только новый
формат передачи сведений.









Если требуемые справочники не заполнены
для поля Вид вставки таблицы передачи сведений в ГИИС ДМДК, то требуется
открыть и заполнить это поле стандартными значениями согласно рекомендациям
ГИИС ДМДК. В справочнике предоставляется возможность самостоятельного указания сокращенного
наименования для каждого элемента справочника, которое участвует при заполнении
полного наименования изделия.



В связи с требованиями обмена данными
с ГИИС ДМДК не допустимо изменять значения реквизитов элементов справочника и
необходимо проверить следующие справочники на заполнение:



● АКСЛМБВидыДк – виды драгоценных камней по ГИИС ДМДК;



● АКСЛМБЦветаДК – цвета драгоценных камней;



● АКСЛМБКачествоДК – качество драгоценных камней;



● АКСЛМБФормаДК – формы огранки драгоценных камней.



В каждом справочнике на форме списка добавлена
команда Заполнить значения справочника, ускоряющая процесс
заполнения.
