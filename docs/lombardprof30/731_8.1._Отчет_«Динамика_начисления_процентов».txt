# 8.1. Отчет «Динамика начисления процентов»



Отчет предназначен для сравнения
сведений по начислению процентов в двух аналогичных периодах и позволяет анализировать
оценить прирост в сравнении с аналогичными прошлыми периодами. Особенности отчета:



● Период отчета – задает ограничение периода, за который
будут выбраны данные, а Шаг периодов сравнения — сдвиг времени назад для получения
аналогичного периода;



● Количество периодов сравнения – дополнительно задается
необходимое количество прошлых периодов для сравнения;



● Шаг периодов сравнения не может быть меньше Периода отчета,
иначе не удастся осуществить сдвиг периода назад.



Отчет отражает информацию по
следующим показателям:



● Начисленные проценты;



● Сумма задолженности по процентам/услугам на конец отчетного
периода;



● Сумма задолженности по процентам, не погашенным в установленный
срок.
