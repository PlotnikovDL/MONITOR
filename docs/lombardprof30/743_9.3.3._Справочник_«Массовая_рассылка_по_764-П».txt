# 9.3.3. Справочник «Массовая рассылка по 764-П»



Справочник предназначен для хранения информации
о случаях отказа от проведения операции, об устранении оснований принятия решения
об отказе от проведения операции.



Обращение к справочнику выполняется
из раздела программы Проверка клиентов 115-ФЗ и пр. — Массовая
рассылка по 764-П по ссылке Реестр лиц (массовая рассылка по 764-П).



В форме списка справочника для пользователей
с ролью Займ и хранение: административные функции также доступна команда
Загрузить список массовой рассылки по 764-П, которая позволяет загрузить
список лиц из xml-файла.



При вводе элемента справочника в шапке
необходимо указать Номер записи в перечне – уникальный номер записи из перечня
Росфинмониторинга. По данному реквизиту осуществляется контроль уникальности элементов
во всем справочнике.






Для каждого элемента справочника включены
следующие табличные части:



● Документы — информация о документах лица из списка массовой
рассылки по Положению 764-П;



● Место рождения — сведения о местах рождения;



● Основания операции — информация обо всех документах-основаниях
отказа.





Важно! Решением «1СЛомбард» не предусматривается и не
рекомендуется самостоятельное заполнение справочника для массовой рассылки.
