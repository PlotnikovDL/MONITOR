# 11.1. Установка конфигурации



Установка конфигурации прикладного решения производится из шаблонов.
Шаблон представляет собой совокупность файлов поставки и сопутствующих файлов, составляющих
прикладное решение, на основании которых производится создание информационной базы.
Установка шаблонов и запись на компьютер пользователя выполняется специальной программой
установки.



Подробное описание процесса установки
шаблонов прикладного решения приведено в книге «1С:Предприятие 8.3. Руководство
администратора».



Перед запуском процесса установки
следует проверить и установить платформу «1С:Предприятие 8». Если платформа на выбранном
компьютере уже установлена, следует убедиться в том, что версия установленной платформы
не ниже 8.3.27. Если версия установленной платформы ниже 8.3.27, необходимо обновить платформу.



Программа установки и обновления setup.exe находится, как правило, в каталоге
platform\setup установочного комплекта
программы (электронная версия) или на компакт-диске, входящему в комплект поставки.



Для того чтобы установить конфигурацию необходимо установить ее
шаблон. Для выполнения установки шаблона конфигурации необходимо вставить диск с
поставкой в устройство для чтения компакт-дисков. Автоматически произойдет запуск
программы и откроется окно программы с выбором режима установки.



В случае электронной поставки необходимо скачать файлы поставки,
распаковать их и запустить файл setup.exe.



Установка для решения «1С:Ломбард КОРП» и решения «1С:Ломбард
ПРОФ» происходит по однотипной схеме, с разницей только в выборе необходимого
шаблона для установки.






Если по каким-либо причинам программа установки конфигурации не
запускается, следует выполнить запуск программы вручную (программа Setup.exe в каталоге
\Configs\LMB\Setup в составе переданного установочного комплекта).



По ссылке Описание установки можно ознакомиться
с процессом установки, содержащим последовательность действий пользователя, включая
установку платформы «1С:Предприятие 8», установку системы лицензирования и защиты
(СЛК), установку драйверов и т.д.



Выберите команду Далее для продолжения установки
и записи шаблонов конфигурации «Ломбард» в каталог шаблонов.



Предложенный по умолчанию путь к каталогу шаблонов можно изменить.
Система выполнит попытку установки шаблона конфигурации в указанный каталог:






После завершения всех шагов описываемой процедуры программа выдаст
сообщение о том, что шаблон конфигурации установлен и на основании шаблона можно
создать информационную базу для дальнейшей работы.






Если при первоначальном запуске список
информационных баз пустой, то пользователю будет предложено создать новую ИБ. Если список содержит ИБ, необходимо выполнить
команду Добавить.






В открывшемся окне Добавление информационной базы/группы
выбрать пункт Создание новой информационной базы.






Необходимо выбрать шаблон «1С:Ломбард» (рабочую или демобазу)
с определенным номером релиза.






После выбора шаблона далее указывается наименование информационной
базы (можно оставить то, которое предлагает программа «1С:Ломбард КОРП, редакция
3.0») и выбирается место ее расположения: На данном компьютере или на компьютере в локальной
сети либо На сервере 1С:Предприятия (используется для работы в клиент-серверном
варианте).






Если выбрано место расположения На сервере 1С:Предприятия,
необходимо указать параметры подключения
информационной базы. Более подробно о создании информационной базы в клиент-серверном
варианте см. в книге «1С:Предприятие 8.3. Руководство администратора».



При выборе места расположения ИБ На данном компьютере или на компьютере
в локальной сети будет создана информационная база в файловом варианте.



На следующем шаге указывается язык (по умолчанию — русский) и
каталог, в котором будет размещена информационная база. Можно указать существующий
каталог или создать новый, который будет создан автоматически после указания имени
несуществующего каталога.






На последнем шаге необходимо сделать финальные настройки (рекомендуется
оставить значения «по умолчанию») и завершить установку выполнением команды Готово.






По завершении данного процесса будет создана информационная база
в указанной Вами папке с заданными параметрами. В окне запуска «1С:Предприятие»
добавится строка с наименованием вновь созданной базы.
