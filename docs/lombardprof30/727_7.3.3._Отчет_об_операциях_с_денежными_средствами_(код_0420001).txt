# 7.3.3. Отчет об операциях с денежными средствами (код 0420001)



Команда для
создания ежемесячного Отчета об операциях с денежными средствами по коду
ОКУД 0420001
помещена в отдельную форму списка,
т.к. не требует корректировки
макета отчетных форм и создается автоматически при выборе в ежемесячной
отчтености Отчета об операциях с денежными средствами.






В открывшемся окне
требуется выбрать период отчета и выполнить команду по кнопке Создать.






Далее командой Заполнить
следует сформировать отчет.






После выполнения
команды следует заполнить раздел, который не будет выводиться на печать с
технической информацией.






Далее следует проверить все разделы отчета
на корректность числовых показателей в информационных разделах отчета.












Следующим и важнм этапом
заполнения Отчета об операциях с денежными средствами, является
осуществление проверки.






Проверка осуществляется корректность присвоения всем Статьям
движения денежных средств Кодов НФО.






Если в
отчете присутствуют ошибки, нужно проверить справочник Движения денежных
средств и заполнить отсутствующие коды НФО.





Важно! Не рекомендуется относить в прочие поступления или
платежи разнородные статьи движения денежных средств, во избежание ошибки при
подготовке отчетности.






После проверки корректности
заполнения файла, отчет необходимо сохранить, выполнив заманду по кнопке Записать.






Сохраненный Отчет об операциях с денежными средствами помещается в типовой список
регламентированных отчетов раздела Отчеты — 1С-Отчетность —
Регламентированные отчеты.
