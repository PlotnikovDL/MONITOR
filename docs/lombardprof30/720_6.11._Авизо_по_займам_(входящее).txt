# 6.11. Авизо по займам (входящее)





Важно! Данный
функционал доступен только в «1С:Ломбард» версии КОРП.






Документ предназначен для отражения операций
по поступлению займа в обособленное подразделение.



Обращение к документу выполняется по
ссылке Авизо по займам (входящее), расположенной на панели разделов Ломбард.






При оформлении документа Авизо по
займам (входящее) заполняются значения по принимающей стороне: Склад и Подразделение.






После заполнения основных реквизитов
шапки следует заполнить таблицу Данные по
контрагентам командой по кнопке Добавить,
затем дозаполнить обязательные поля и рассчитать стоимость предметов.






После проведения документа создаются бухгалтерские
проводки, отражающие проведенную операцию.
