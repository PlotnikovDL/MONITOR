# 6.4.1. Документ «Перезалог» с изменением срока



В документе Перезалог с изменением срока предоставляется ограниченная
возможность изменить следующие параметры:



● Сумма погашения всего;



● Срок.






После изменения значений реквизитов необходимо
подобрать новый залоговый билет и выполнить действие Рассчитать стоимость.



После проведения документа формируется
проводка по доначислению процентов на дату перезалога и происходит движение по регистрам
Залоговых билетов.



Движения документа Перезалог отражаются на счетах РСБУ
следующими проводками:



● Списание бланка строгой отчетности по Кт забалансового
счета 006 «Бланки строгой отчетности»;



● На сумму дополнительных процентов по Дт счета 58.03.2
«Проценты по предоставленным займам» в Кт счета 90.01.1 «Выручка по
деятельности с основной системой налогообложения».






Движения документа Перезалог делает проводки на ЕПС:



● Для списания бланка строгой отчетности по Дт счета
99999 «Счет для корреспонденции с активными счетами при двойной записи» и по Кт
счета 91223 «Бланки строгой отчетности»;



● На сумму дополнительных процентов по Дт счета 48602
«Начисленные проценты по займам, выданным физическим лицам» в Кт счета 71001
«Процентные доходы».






Документ Перезалог также предоставляет возможность вывести на печать форму
залогового билета, используется из встроенного меню по кнопке Печать
команда Залоговый билет (новый).
