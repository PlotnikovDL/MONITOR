# 6.2.4. Документ «Установка ставки по драгоценным металлам»



Документ предназначен для установки ставок
по драгоценным металлам для автоматизированной оценки предметов залога и размера
предоставляемой суммы займа в документе Выдача
займа, получение залога. Оценка для предмета залога устанавливается за грамм
металла. Доступна установка разных оценок для разных категорий заемщиков и состояний
изделий. Документ по установке ставок содержит несколько разделов.



В основном разделе Металлы для каждого драгоценного
металла устанавливается ставка по «базовой пробе», исходя из которой
определяется стоимость для других проб (в соответствии с коэффициентом
пересчета, указанным для пробы металла).



В дополнительном разделе Пробы
выполняется заполнение проб и расчет стоимости для каждой пробы драгоценного
металла. Процесс наполнения раздела данными запускается по команде Заполнить данные по пробам.
