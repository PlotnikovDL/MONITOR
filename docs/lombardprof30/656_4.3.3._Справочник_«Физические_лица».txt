# 4.3.3. Справочник «Физические лица»



Обратиться к справочнику Физические
лица можно по ссылке на панели разделов Справочники — Зарплата и кадры.






В конфигурации «Ломбард» предусмотрен
признак по определению клиента ломбарда — признак устанавливается автоматически
при проведении первой выдачи займа физическому лицу. Дополнительно в карточке физического
лица для клиентов ломбарда предусмотрены для заполнения дополнительные вкладки:



● Клиент ломбарда, где может заполняться категория клиента
ломбарда, а также устанавливается согласие клиента на получение рассылок и оповещений
посредством электронной почты и (или) SMS-сообщений;



● Анкетные данные клиента, где может заполняться информация
о клиенте, предназначенная для переноса данных в печатную форму документа Анкета
клиента.






Вывод печатной формы документа Анкета клиента
доступен по кнопке Печать — Анкета клиента (досье)
