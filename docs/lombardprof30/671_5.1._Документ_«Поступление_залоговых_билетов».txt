# 5.1. Документ «Поступление залоговых билетов»



Документ Поступление бланков предназначен для регистрации поступающих бланков
строгой отчетности в организацию. Документ
располагается в разделе Ломбард — Учет бланков по ссылке Поступление бланков.






Форма
документа Поступление бланков содержит
следующие реквизиты для заполнения:



● Организация — организация, в которой будет вестись учет
бланков строгой отчетности;



● Склад — склад, на который будут приняты бланки;



● Подразделение — подразделение, у которого будут учитываться
бланки;



● закладка Бланки — таблица для ввода информации о поступающих
бланках.






Ввод информации по бланкам строгой отчетности
осуществляется с регистрацией групп номеров (диапазонов) бланков:



● В колонке Вид бланка
указывается название или вид бланка;



● В колонке Серия
— серия залоговых билетов;



● В колонке Начало
диапазона указывается первый номер залогового билета в диапазоне;



● В колонке Конец диапазона
указывается последний номер залогового билета в диапазоне. Если вводится один залоговый
билет, то его номер указывается и в начале и в конце диапазона;



● Колонка Количество
не редактируется, а только отражает информацию для контроля количества поступающих
залоговых билетов.



Отражение операций по залоговым билетам
производится в регистре Состояния бланков. Также в этом регистре указывается
статус, который приобретает залоговый билет. При оформлении документа Поступление бланков все залоговые билеты
приобретают статус Принят.
