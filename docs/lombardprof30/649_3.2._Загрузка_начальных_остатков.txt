# 3.2. Загрузка начальных остатков



Для загрузки начальных остатков в решении
«1С:Ломбард» предусмотрена специальная обработка файлов с остатками в формате Microsoft
Excel (*.xls или *.xlsx). Выполнение обработки выполняется из формы документа Ввод начальных остатков (займы, хранение).






При выборе команды Загрузка остатков открывается
окно специальной формы для выполнения операций загрузки.



В обработке представлен сам шаблон загрузки
данных для текущей версии конфигурации. Этот шаблон представляет собой файл, который
используется для импорта начальных остатков в базу, его можно сохранить и использовать
для заполнения. Выгрузка выполняется из встроенного меню по кнопке Еще
на форме обработки.






После сохранения шаблона в него необходимо
внести данные по договорам займам, предметам залога. Заполненный файл может быть
загружен в документ ввода начальных остатков. Структура файла загрузки содержит
следующие поля для загрузки ввода начальных данных:



● ФИО клиента — указывается полностью, например «Иванов
Иван Иванович»;



● Дата рождения клиента — указывается дата в формате
ДД.ММ.ГГГГ, например «01.02.1995»;



● Пол клиента — выбирается одно из двух значений «Мужской»
или «Женский»;



● Гражданство клиента — выбирается значение по умолчанию
«РОССИЯ»;



● Вид документа, удостоверяющего личность — по умолчанию
устанавливается «Паспорт гражданина РФ»;



● Документ серия — указывает номер серии без пробелов и
прочерков, например «4514»;



● Документ номер — указывается номер документа;



● Документ кем выдан — записываются сведения об органе регистрации,
например «ОУФМС по гор. Москве»;



● Документ дата выдачи — указывается дата в формате
ДД.ММ.ГГГГ;



● Документ код подразделения — записывается код
территориального подразделения, к примеру «752-421»;



● Документ срок действия — указывается дата в формате
ДД.ММ.ГГГГ;



● ИНН клиента — записывается идентификационный номер
налогоплательщика;



● Серия залогового билета — вводится информация о серии
бланка строгой отчетности;



● Номер залогового билета — вводится информация о номере
бланка строгой отчетности;



● Наименование предмета — краткое название предмета,
передаваемого в залог;



● Полное наименование предмета — точное и полное
наименование предмета передаваемого в
залог;



● Тип предмета — указывается вид изделия, например «Ювелирное
изделие»;



● Металл предмета — основной металл, из которого состоит
изделие, к примеру «Золото»;



● Проба предмета — проба металла (585);



● Вес предмета — вес изделия в граммах (10 гр.)



● Чистый вес предмета — вес без примесей, вставок и
добавок (9,7 гр.)



● Описание вставок дефектов предмета — вес вставок и
дефектов (0,3 гр.);



● Предмет количество — указывается количество
передаваемых предметов в залог, как правило «1»;



● Оценка предмета — оценочная стоимость предмета;



● Предмет сумма займа — 
сумм заемных средств по предмету;



● Договор: дата начала — дата начала действия договора,



● Договор: срок (дни) — срок действия договора займа в
днях;



● Договор: дата окончания — дата окончания действия договора;



● Договор: окончание льготного периода — указывается дата, до которой действуют
льготные условия;



● Договор: условия — как правило, устанавливается «Схема-только
проценты»;



● Договор: вид начисления — устанавливается «Процент за
использование займа»;



● Начисление: сумма начисленная — указывается
начисленная сумма процентов;



● Начисление: сумма оплаченная — указывается уплаченная сумма по процентам;



● Адрес по прописке, Адрес места проживания —
записывается полный адрес заемщика, например «г.Москва улица Митинская дом 3
кв. 123»;



● Телефон рабочий, Телефон домашний — записывается номер
телефона в формате «8 (495) 123-45-67».



Для выполнения операции по загрузке остатков
из файла необходимо:



● выбрать файл загрузки по команде Загрузить файл;



● настроить соответствие загружаемых данных в Таблице для загрузки;



● перенести данные из файла в документ с помощью команды
Заполнить документ.



После
выбора файла и его загрузки в форме обработки заполнятся поля Табличный
документ и Таблица для загрузки (далее данные из таблицы для загрузки непосредственно
переносятся в документ ввода остатков). Ссылочные поля отмечаются специальным значком
с изображением карандаша и такие поля можно редактировать.






В обработке загрузки остатков реализован
механизм сопоставления данных колонок. Сопоставление данных выполняется из заполненной
ячейки вызовом контекстного меню по нажатию правой кнопки мыши.



Для каждой из ссылочных колонок данные
сопоставляются с соответствующим справочником базы, например: не найденный клиент
(ошибка в указании даты рождения или помарка в ФИО) может быть сопоставлен с существующим
физическим лицом из базы данных. Установленное сопоставление по правилам поиска
будет применено к остальным строкам таблицы.



После того как все необходимые данные
заполнены, выполняется команда Заполнить
документ, сопоставленные данные из файла перейдут в документ ввода начальных
остатков.
