# 6.1.6. Параметры учета автотранспорта




## Справочник «Марки и модели автомобилей»



Справочник по маркам и моделям автотранспорта
используется для номенклатурных позиций и товаров с установленным значением типа
изделия Автомобиль.



Открывается справочника из раздела
программы Ломбард: Настройки — Учет предметов залога и вещей на хранении
по ссылке Марки автомобилей.






Командой по кнопке Создать открывается форма элемента справочника,
в которой выполняется заполнение сведений по марке автомобиля и списку моделей с
приблизительной оценочной стоимостью.







## Дополнительная информация по автотранспорту



При заполнении карточки номенклатуры для
транспортных средств реализована возможность указания ключевых параметров, идентифицирующих
объект:



● ПТС — реквизиты паспорта транспортного средства;



● VIN — VIN номер автомобиля;



● Номер двигателя — номер двигателя транспортного средства;



● Номер кузова — номер кузова автомобиля;



● Номер шасси — номер шасси автомобиля;



● Гос. номер — государственный номер транспортного средства



● Год выпуска — год выпуска транспортного средства;



● Пробег — пробег автомобиля.






Все документы по транспортному средству
могут быть приложены к предмету залога в виде файлов с электронной копией документа.



Для автотранспортных средств реализована
форма осмотра транспортного средства, вызывается по команде Акт осмотра АТС.






Форма при создании заполняется
информацией, указанной о предмете залога, и может быть дополнена описанием
особенностей или повреждений автомобиля в электронном или письменном виде.
После заполнения описания акт осмотра рекомендуется приложить к предмету залога
в составе файлов (см. раздел руководства Присоединенные
файлы).
