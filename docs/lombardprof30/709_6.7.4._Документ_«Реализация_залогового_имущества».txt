# 6.7.4. Документ «Реализация залогового имущества»



Документ Передача на реализацию можно
сформировать из одноименной формы списка, расположенной в подразделе Ломбард — Продажа и изъятие залогового имущества — Передача
на реализацию.






Новый документ Передача на реализацию создается из списка документов по реализации
по кнопке Создать. Кроме
этого, можно скопировать, используя уже готовый документ, с максимально
необходимым
числом полей в новый документ и внести необходимые изменения.






Решение позволяет из документа Передача
на реализацию, способом «создать
на основании» также сформировать следующий в процессе учета операций документ Реализация залогового
имущества.






При этом происходит заполнение полей,
по которым имеется информация в документе передачи.








Важно! Документ Реализация залогового имущества
используется для продажи ломбардами имущества. Для изделий дешевле 300 тыс.
руб. этот документ может быть сформирован на основании документа Передача на реализацию.



Для изделий
стоимостью от и выше 300 тыс. руб. документ может быть сформирован на основании
документа Проведение торгов.






Посмотреть документы можно путем
выбора в панели разделов программы Ломбард — Продажа и изъятие залогового
имущества ссылки Реализация залогового имущества.






В создаваемом документе необходимо
заполнить реквизиты Покупатель, Договор, Сумму реализации
и выполнить команды Рассчитать проценты и Рассчитать
резервы.






После проведения документа запись
хозяйственных операций (проводок) выполняется, в следующем порядке:



● списание залогового имущества;



● доначисление процентов;



● списание процентов по займу;



● выбытие займа;



● отражение задолженности в пользу залогодателя (при
наличии);



● зачет обязательств между покупателем залоговых вещей и
заемщиком;



● списание отрицательной разницы — убытка от реализации
(при наличии)



При ведении учета по РСБУ
сформируются проводки по счетам общехозяйственного плана счетов, а при ведении
учета по ЕПС – записи проводок по плану счетов для некредитных финансовых организаций.
