# 2.1.7. Настройка параметров счетов учета для объектов вложений



Счета
учетов объектов строительства организаций
необходимы для обработки информации по объектам вложений в сооружение (строительство),
создание (изготовление) и приобретение основных средств. Счета учетов объектов строительства
позволяют автоматически заполнить счета учета и НДС в документах Поступление объектов строительства и Передача оборудования в монтаж (раздел
ОС и НМА в программе).



Объект вложения (объект строительства
или приобретения основных средств) является объектом аналитического учета, на котором
будут собираться затраты, например: «по приобретению и монтажу оборудования».



Для ввода новой записи необходимо использовать
команду Создать.






В открывшейся форме необходимо заполнить
следующие данные:



● Организация — указывается запись из справочника, содержащая
сведения о некредитной финансовой организации (НФО), для которой выполняется настройка,
если поле Организация не заполнено, параметры отражения счета применяются для всех
организаций, учет деятельности которых ведется в информационной базе;



● Объект строительства — сведения об объекте строительства,
для которого выполняется настройка параметров, если поле не заполнено, параметры
действует для всех объектов строительства заданной организации;



● Счет бухгалтерского учета — счет учета объекта строительства,
для которого выполняется настройка параметров;



● Счет бухгалтерского учета НДС — указывается счет НДС для
объекта строительства;



● Способ учета НДС — значение параметра устанавливается для
организации с раздельным учетом НДС.
