# 7.3.1. Бухгалтерский баланс (код 0420901)



Форма Бухгалтерский
баланс НФО создается из Комплекта отчетности бухгалтерской
(финанасовой) отчетности по 844-П при выполнении команды по кнопке Создать.


















В открывшейся форме Бухгалерский
баланс НФО (Экземпляр отчета) (создание…) по кнопке Заполнить, форма
будет автозаполнена цифровыми показателями из учета и установленных настроек
формы.









При возникновении ошибок в заполнении
отчетных форм, для их устранения требуется повторно закрыть период – выполнить
регламентные операции или заново зайти в настройку отчетных форм и
откорректировать макет отчетности в соответствии с разделом Корректировка
отчетов БФО в программе «1С:Ломбард» настоящего
руководства. После этого сформировать отчетность заново.
