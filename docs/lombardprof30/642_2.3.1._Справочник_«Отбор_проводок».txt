# 2.3.1. Справочник «Отбор проводок»



Открытие справочника со списком
отбираемых проводок выполняется из панели разделов программы Администрирование
и настройка НФО выбором команды Отбор проводок (группа в
разделе программы Настройка трансляции и формирования лицевых счетов).






Справочник содержит параметры для
быстрого получения информации по заданным критериям из операций и проводок
бухгалтерского учета.






В форме отдельного элемента справочника
Отбор проводок задается следующая информация:



● Наименование — наименование фильтра (отбора)
определяет уникальное имя набора данных в записи (элемента справочника) с
настроенными параметрами отбора;



● Отбор — список полей из записи хозяйственных операций,
отражающий вид отбора, условие и значение для отбора.



При задании отборов предоставлена
возможность группировать условия с условием «И/ИЛИ» с различным уровнем
вложенности группировок.





Важно! На самом верхнем уровне списка отбора всегда
действует условие выполнения «при одновременном выполнении всех условий» (логическая
функция «И»). уровня. При этом элементами верхнего уровня могут быть конкретные
отбору или группы отборов. Внутри групп и подгрупп могут создаваться также
условия «при выполнении одного из условий» (логическая функция «ИЛИ»), а также
«НЕ» выполнении условий.






Для перечня параметров и условий, по
которым может быть выполнен отбор проводок, могут использоваться следующие
показатели:



● Субконто – устанавливается определенное субконто счета,
по которому необходимо выполнить отбор проводок (Субконто1, Субконто 2,
Субконто 3,…), порядок не превышает заданного количества используемых
субконто на счетах;



● Корр. субконто — устанавливается соответствующее корр.
субконто счета по корреспондирующему счету; 



● Валюта — устанавливается признак валюты по отбираемым
проводкам;



● Сумма – в качестве устанавливается числовое значение
проводки для отбора;



● Номер строки – устанавливается постоянный номер строки
искомой проводки в документе;



● Организация – устанавливается отбор по общему реквизиту
для проводок;



Указанный выше перечень отборов не
является исчерпывающим, полный список определяется параметрами проводок. Необходимость
определения групп условий для отбора определяется пользователе самостоятельно.
