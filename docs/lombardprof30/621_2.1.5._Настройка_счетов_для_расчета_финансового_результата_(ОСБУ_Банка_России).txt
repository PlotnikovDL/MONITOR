# 2.1.5. Настройка счетов для расчета финансового результата (ОСБУ Банка России)



Для переноса доходов и расходов необходимо
настроить соответствие счетов учета путем заполнения регистра сведений Соответствие счетов для переноса доходов и расходов.
Для этого следует выбрать на панели разделов программы Администрирование и настройка НФО ссылку Соответствие счетов
для переноса доходов и расходов в группе Настройки.






Выполнение команды по кнопке Заполнить формирует список счетов для переноса
доходов и расходов, этот список хранится в регистре сведений Соответствие счетов для переноса доходов и расходов.
