# 9.3.2. Регистр сведений «История проверки МВК»



Регистр предназначен для хранения информации
об истории проверок клиентов ломбарда на соответствие лицам, включенных в решения
межведомственной комиссии по противодействию финансированию терроризма.



Обращение к регистру выполняется из
раздела программы Проверка клиентов 115-ФЗ и пр. – МВК по ссылке История проверки
МВК.



Каждая запись в регистре отражает
следующую информацию:






● Период – дата проверки клиента;



● Клиент – контрагент/физическое лицо, которое проверялось;



● Лицо МВК – соответствующее клиенту лицо МВК;



● Результат проверки – признак, по которому было найдено
соответствие.



Запись в регистр возможна в следующих
случаях:



● при записи сведений из формы контрагента/физического лица;



● при выполнении регламентного задания Тотальная проверка
клиентов по 115-ФЗ (Ломбард).
