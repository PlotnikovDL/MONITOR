# 6.9.3. Рабочее место товароведа: заполнение таблицы вставок ГИИС ДМДК в карточке залогового изделия



Для заполнения характеристик по вставкам
в ювелирных изделиях в форме создаваемой номенклатуры необходимо применить параметр
Вставки ГИИС ДМДК, после чего появляется табличная часть для заполнения
сведений по характеристикам вставок, их весу, количеству, оценке и сумме займа.
Характеристики камней заполняются на основании ранее загруженных справочников по
типу и виду вставок, характеристикам, цвету, качеству и форме огранки.



ГИИС ДМДК определяет три вида вставок:



1) 
Вставки ДК:



Порядок заполнения полей в этом
случае будет следующий:



● 
Тип вставки ГИИС ДМДК — устанавливается значение Вставки
ДК из списка предопределенных значений;



● 
Вид вставки заполняется значением из справочника Виды драгоценных
камней ГИИС ДМДК, значение устанавливается в соответствие с видом вставки в
ювелирном изделии, принимаемым в залог.



Описание прочих вставок может заполняться
только для тех вставок в ювелирные изделия, которые на являются драгоценными камнями.



● 
Цвета ДК – заполняется сведениями из справочника Цвета ДК;



● 
Качество ДК – заполняется сведениями из справочника Качество ДК;



● 
Форма огранки ДК – заполняется из справочника Формы огранки ДК.



Поля Характеристики самородков
не подлежат заполнению.






Поле Вес/% – заполняется
значением из предопределенного списка Вес.



Поле за шт. — заполняется значением
веса в граммах одной единицы вставки.



Поле штук — заполняется значением
количества драгоценных камней с одинаковыми характеристиками.



Значение Корр. Веса заполняется
автоматически.









2) 
Вставки Самородки
ДМ:



Заполнение табличной части производится
аналогично варианту Вставки ДК на с заполнением полей Характеристики
самородков.






3) 
Прочие вставки:



● 
Тип вставки ГИИС ДМДК
— устанавливается как значение Прочие вставки;



● 
Поле Описание прочих
вставок заполняется описанием прочих вставок в свободной форме, значение этого
поля будет использоваться при заполнении полного наименования изделия (присутствует
ограничение по длине строки — не более 70 символов);



● 
Заполнение полей Вес/%,
за шт., Корр. Веса производится аналогично порядку
заполнения указанных полей, описанному выше по Вставки ДК.



Другие поля для прочих вставок заполнению
не подлежат.












Все введенные данные влияют на дальнейшее
заполнение поля Полное наименование.



Для применения сокращенных наименований
для характеристик вставок ДК необходимо для каждого элемента справочников Цвета
ДК, Качество ДК, Формы огранки ДК присвоить сокращенное наименование, а
также при заполнении формы номенклатуры установить признак Использовать сокращения
из справочника для формирования полного наименования.






Таким образом, если до выполнения
процедур полное наименование формировалось по правилам пользователя.






После присвоения сокращенных
наименований образуется достаточна четкая структура в описании вставок.
