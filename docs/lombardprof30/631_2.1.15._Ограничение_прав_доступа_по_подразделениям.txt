# 2.1.15. Ограничение прав доступа по подразделениям





Примечание. Данный
функционал доступен только в конфигурации «Ломбард» версии КОРП.






Управление настройкой прав доступа по
подразделениям находится в разделе программы Ломбард:Настройки — Настройка
по ссылке Настройка функциональных опций НФО.






Параметры формы настройки содержат
закладку Ограничения. На этой закладке выполняется установка блокировок Ограничения по реализации, Ограничения по перезалогу,
Ограничения по номенклатуре, Ограничения по займам. Для каждого параметра из
ограничений в форме отражается краткая информация.
