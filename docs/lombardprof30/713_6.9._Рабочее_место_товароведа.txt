# 6.9. Рабочее место товароведа



Информационный блок Рабочее место товароведа
предназначен для быстрого совершения операций по займам в ломбарде: по выдаче займа,
перезалогу и возврату займа.



Блок Рабочее место товароведа располагается
в разделе программы Ломбард.






Окно рабочего места содержит следующие
разделы:



● Командную панель с возможностью быстрого создания документов
по выдаче займов, перезалогам, возвратам займов;



● Отборы по заемщикам, договорам и состояниям залоговых билетов;



● Табличную часть с перечнем залоговых билетов;



● Табличную часть с операциями по выбранному залоговому билету.






Расширенные возможности отбора значений
для таблицы раскрываются по кнопке Еще и выбором в выпадающем меню ссылки
Настроить список.






Использование
Рабочего места товароведа позволяет выполнить все основные операции и
сформировать необходимые документы.
