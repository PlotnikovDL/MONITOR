# 2.1.12. Счета для целей расчета налога на прибыль (ОСБУ Банка России)



Для расчета налога на прибыль в системе
необходимо заполнить регистр сведений Счета
учета прибылей и убытков для целей расчета налога на прибыль.





Важно! Указанную настройку следует использовать только после перехода
на прямой учет. На период трансляции настройки не выполняются.






Настройка параметров учета в регистре
Счета учета прибылей и убытков для целей расчета налога на прибыль можно
путем последовательного выбора на панели разделов Учет НФО — Регламентные операции
НФО — Счета учета прибылей и убытков для целей расчета налога на прибыль.






Для ввода новой записи по счету учета
необходимо выполнить команду Создать.






Счет — указывается счет, обороты по которому будут браться
при расчете налога на прибыль.



В программном решении «1С:Ломбард» необходимо задать счет учета по налогу на прибыль и аналитику к
этому счету.



Для того, чтобы установить счет учета
по налогу на прибыль необходимо выбрать на панели разделов Главное — Настройки — Налоги и отчеты вкладку Налог на прибыль.
