# 2.1.1. План счетов



Проверка заполнения плана счетов выполняется
командой План счетов, расположенной
на панели рабочего стола при обращении
к разделу программы Главное.






В решении «1С:Ломбард» план счетов бухгалтерского
учета отображается в двух видах – в виде РСБУ (вкладка РСБУ) и виде ЕПС (вкладка ЕПС).









Отнесение счета к плану счетов РСБУ или
плану счетов ОСБУ Банка России определяется установкой отметки Счет ЕПС
для каждого счета. Когда отметка установлена, счет отражается на вкладке ЕПС.
Если отметка отсутствует, счет отображается на вкладке РСБУ.









Загрузка плана счетов ЕПС выполняется
через выбор на панели разделов программы Администрирование и настройка НФО в
группе Сервис команды Загрузка плана счетов.






Данная загрузка позволяет добавлять новые
счета, изменять наименования старых счетов и помечать на удаление счета, которые
уже не используются в соответствии с Положением Банка России № 803-П от
01.08.2022 г. «О плане счетов бухгалтерского учета для некредитных финансовых
организаций, бюро кредитных историй, кредитных рейтинговых агентств и порядке
его применения» и нормативными документами по изменению этого Положения.



Параметры использования объектов аналитического
учета и признаки учета по ранее загруженным счетам, не изменяются.



Процедура загрузки позволяет с помощью
команды Загрузить из встроенного макета и установленной отметки Не
менять статус РСБУ у текущих счетов загрузить ЕПС в систему.



При необходимости, когда выходят изменения
в структуре плана счетов Банка России, обеспечивается возможность загрузки этих
изменений, используя команду Загрузить изменения по версиям. Можно
указать с какой версии конфигурации необходимо загрузить изменения.






Отметка Не менять статус РСБУ у текущих счетов (применяется только один раз
при первоначальной загрузке) – используется для того, чтобы при загрузке счетов
выделить счета, которые будут относиться к ЕПС. Использование отметки укажет, что
все счета, которые выбраны в текущей загрузке в план счетов, относятся к плану счетов
РСБУ.





Важно! Рекомендуется использовать отдельную загрузку счетов для
плана счетов РСБУ и отдельную загрузку для плана счетов Банка России.






Для добавления новых счетов необходимо
установить отметку у Только подгрузить новые
счета и выполнить команду по кнопке Загрузить
изменения по версиям.
