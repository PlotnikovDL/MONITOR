# 2.1.2. Виды доходов и расходов (Символы ОФР)



Все виды доходов и расходов (Символы ОФР
для учета по ОСБУ Банка России) хранятся в соответствующем справочнике, к которому
можно обратиться из панели разделов программы Учет НФО — Виды доходов и расходов (Символы ОФР).






По команде Автоматическое заполнение выполняется загрузка данных по символам
ОФР из встроенного шаблона 612-П. Значения
из этого справочника в дальнейшем используются пользователем при выборе символов
ОФР в справочнике Прочие доходы и расходы.






Справочник Прочие расходы и доходы обеспечивает ввод, хранение и изменение записей
по статьям расходов и доходов для дальнейшего использования в объектах учета.
