# 6.7.5. Документ «Отсрочка реализации»



Документ предназначен для оформления отсрочки
реализации залогового имущества. Список документов открывается из раздела
программы Ломбард — Продажа и изъятие залогового имущества по ссылке Отсрочка реализации.






При создании нового документа
заполняются обязательные поля: Подразделение организации, Согласующий
и устанавливается при необходимости, когда все данные проверены, отметка Согласовано.
В табличную часть добавляются новые записи по контрагентам с использованием
команды по кнопке Добавить.






Программой предоставляется
возможность заполнить список по просроченным договорам с помощью команды Просроченные договоры из выпадающего
списка по кнопке Заполнить. В таблицу попадают все контрагенты с
просроченными договорами на дату формирования документа.









В случае, если какаята запись в
таблице с указанием контрагента и договора не нужна, эту запись можно удалить соответствующей
командой из встроенного меню по кнопке Еще.






Для внесения изменений в условия отсрочки
изменяется значение в поле Дата отсрочки у требуемых нам договоров.
После внесения изменений устанавливается признак Согласовано и проводится
документ.
