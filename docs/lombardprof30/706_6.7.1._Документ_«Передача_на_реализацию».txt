# 6.7.1. Документ «Передача на реализацию»



Документ Передача на реализацию предназначен для учета в системе «1С:Ломбард»
обращений по взысканию на невостребованные залоговые изделия по договорам займа
с истекшим льготным периодом, а также проверки наличия маркировки перед розничной
реализацией изделий из драгоценных металлов и драгоценных камней.



Документ Передача на реализацию располагается в разделе программы Ломбард – Передача на реализацию.
Работа с документом предполагает прохождение нескольких этапов.







## Заполнение документа



Для
формирования нового документа в форме списка документов необходимо выбрать команду
Создать,
после чего заполнить новый документ.












Основные реквизиты документа, которые
необходимо заполнить:



● Организация — поле отражает организацию от лица
которой ведется учет в системе, значение автоматически заполняется «по
умолчанию» элементом из справочника Организации, используемому в системе и
установленному в настройках пользователя;



● Подразделение – подразделение организации, от лица которой
оформляется документ.



Табличная часть документа Заполнение списка договоров может
заполняться следующими способами:



● Самостоятельно пользователем, используя команду Добавить или Подбор;






● автоматически по команде Заполнить и выбором из выпадающего меню пункта Просроченными договорами;






● с применением стороннего оборудования для чтения
штриховых кодов.



Независимо от выбранного способа
заполнения списка договоров при заполнении табличной части автоматически
отобразятся данные по каждому договору, а также заполнится табличная часть с
перечнем залоговых изделий, принятых по договорам.






Кроме этого, табличная часть
документа Статус реализации также
может заполняться следующими способами:



● самостоятельно пользователем;



● по группе договоров – для этого в списке элементов
Статус реализации (выше) выбрать два или более договора, после чего
использовать команду Заполнить и выбрать последовательно Установить –
Статусы реализации, а затем выбрать один из предложенных статусов реализации.



Табличная часть документа: Дата
планируемой реализации — заполняется пользователем самостоятельно;



Табличная часть документа: Стоимость
реализации — может заполняться двумя способами: (это другой документ)



● самостоятельно пользователем;



● по группе договоров: для этого в списке выбрать два
или более договоров, после чего выбрать последовательно команду Заполнить,
далее Установить и выбрать Стоимость реализации коэффициентом, установить
повышающий или понижающий коэффициент для расчета стоимости реализации, применить
установленный коэффициент по команде Ок.








Важно! В одном
документе Передача на реализацию может заполняться только один тип статуса
реализации. В случае, если пользователь попытается провести документ, в котором
установлены разные статусы реализации, и создать какие-либо связанные документы
(используя команду Создать на основании), система выдаст сообщение об ошибке «В передаче на реализации присутствуют разные
статусы передачи».







## Проверка наличия маркировки для изделий из драгоценных металлов и драгоценных камней



Под табличной частью документа Передача на реализацию имеется поле для
отображения номенклатуры с типом изделия, УИН, и прочих показателей маркировки
залогов. А также есть гиперссылка для проверки ювелирных изделий.






Для залогов, не являющихся ювелирными
изделиями, и для ювелирных изделий, не предназначенных для розничной
реализации, значение столбца индикации состояния автоматически принимает вид
отметки серого цвета,
и проверка маркировки для таких залоговых предметов не требуется. Для залоговых
предметов как ювелирные изделия отметка о маркировке окрашивается в зеленый
цвет и устанавливается пользователем.



Выполнение проверки маркировки
ювелирных изделий выполняется в несколько шагов:



● необходимо выбрать команду Проверить ювелирные
изделия;



● выбрать команду Проверить по УИН и указать
уникальный идентификатор ювелирного изделия



● выполнить команду Выбрать (для ввода УИН также
может быть применено стороннее оборудование для сканирования штрихового кода);



● после заполнения (проверки) УИН по всем ювелирным
изделиям применить команду Перенести в документ.






После выполнения проверки ювелирных
изделий в табличной части с залоговыми изделиями в колонке таблицы Маркировка
обновятся отметки по каждому ювелирному изделию, по которому была проведена
проверка по УИН.






В случае, если хотя бы по одному
ювелирному изделию, требующему маркировку, не будет выполнена проверка по УИН,
тогда при попытке проведения документа система отобразит предупреждающее
сообщение об отсутствии такой проверки по этому изделию.






После заполнения документ
записывается, выполняется команда Провести или Провести и
закрыть.
