# 6.9.4. Рабочее место товароведа: операции перезалога



При создании перезалога по действующему
договору и для того, чтобы не заполнять заново реквизиты документа Перезалог
в части физического лица — заемщика и договора, перед созданием операции необходимо
в окне Рабочее место товароведа установить отбор, соответствующий искомому
заемщику и договору. При этом в случае попытки создания документа Перезалог
без предварительного отбора по физическому лицу, будет выведено сообщение «Не
задан отбор по залогодателю».



После выбора команды Перезалог
для оформления нового предоставляется на выбор два вида документов по следующим
операциям:



● Изменение срока — вид операции может использоваться только
при продлении срока займа;



● Изменение условий — вид операции используется при изменении
условий и продлении.












Уже в форме созданного документа Перезалог
заполняются и проверяются следующие поля:



● Значения реквизитов Организация, Склад, Подразделение
– поля могут быть предварительно заполнены при условии наличия настроенных
параметров по ограничению прав для пользователя, выполняющего текущую операцию;



● Сумма погашения (всего) — значение рассчитывается автоматически
и заполняется суммой процентов, начисленных на дату оформляемого документа Перезалог
(в случае, если заемщик намерен внести определенную сумму, значение поля необходимо
скорректировать);



● Погашен займа — поле автоматически заполняется значением
«0», в случае, когда заемщик намерен внести определенную сумму в счет погашения
основного долга, значение поля необходимо скорректировать, при этом поле Сумма погашения
(всего) автоматически будет также пересчитано с учетом частичного досрочного погашения;



● Подбор бланка — операция производится вручную из доступного
списка бланков, вызываемого по команде Подбор бланка или выполняется системой
автоматически по команде Обновить содержимое;



● Изменить условия займа (схему расчета) — новые условия
для займа выбираются только в случае, если при создании перезалога был выбран тип
документа Изменение условий;



● Срок, дней — новый срок действия договора
(устанавливается с даты изменения условий);



● Рассчитать стоимость — применяется для расчета
стоимости с изменившимися условиями.



После
заполнения и проверки документа завершающим шагом следует команда Провести.






После проведения документа можно:



● 
получить печатную форму залогового билета по документу перезалога, используя
команду Печать;



● 
создать на основании проведенного документа Перезалог, документ об
оплате: кассовый документ при получении наличных или документ Операция по
платежной карте.






При создании документов способом «создать
на основании» происходит автоматическое заполнение создаваемых документы,
достаточно проверить корректность заполнения и выполнить команду Провести
или Провести и закрыть. Печать чека, при наличии подключенного
оборудования, производится с помощью команды Чек в выпадающем меню Ещё.
