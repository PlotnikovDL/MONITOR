# 2.2.6. Выбор организации для определения вида учета



Для установки соответствия вида учета
(РСБУ или ЕПС) конкретной организации необходимо задать организацию. Для этого необходимо
в панели разделов Администрирование и настройка
НФО — Сервис перейти по ссылке Организация
для определения учета.








Важно! Значение Организация для определения учета НФО
должно быть всегда заполнено, так как учетная политика данной организации
определяет индивидуальное ведение учета НФО и не может устанавливать правила
ведения учета НФО по другим организациям, по которым ведется учет в одной
программе.
