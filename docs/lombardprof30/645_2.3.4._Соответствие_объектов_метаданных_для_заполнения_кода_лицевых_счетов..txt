# 2.3.4. Соответствие объектов метаданных для заполнения кода лицевых счетов.



Метаданные – представляют собой
специальные данные, которые описывают структуру базы данных и объекты
конфигурации. Это справочники, регистры сведений и накопления, где хранятся
сведения об объектах системы. Данные списки являются константами (не должны
редактироваться) и предназначены для обеспечения работы программы. Метаданные в
системе должны соответствовать друг другу.



Списки метаданных заполняются
автоматически при первом запуске, согласно метаданным программы, а также
автоматически актуализируется при каждом обновлении версии программы
(учитываются переименованные, добавленные и удаленные объекты метаданных).



Наличие списков с метаданным
позволяет упростить назначение отборов в различных списках и документах
системы, особенно при сопоставлении данных:



● Тип объекта — особая система, по которой организуются
данные;



● Номер — порядковый номер документа, значение обычно заполняется
автоматически.
