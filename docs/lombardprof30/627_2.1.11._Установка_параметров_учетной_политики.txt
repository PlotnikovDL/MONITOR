# 2.1.11. Установка параметров учетной политики



Установка параметров учетной политики
выполняется таким же образом, как и при работе в «1С:Бухгалтерия 8». В то же
время в решении «1С:Ломбард» имеется своя особенность, в частности
установленная отметка в поле Используется учет по новым стандартам
(ЕПС) — влияет на работу системы и применение этой настройки в дальнейшем
позволяет отражать учет уже по отраслевым стандартам бухгалтерского учета (ОСБУ),
установленному Банком России для НФО. В зависимости от установки отметки система
может работать в трех режимах:



● учет по РСБУ — когда отметка Используется учет по новым стандартам
(ЕПС) не установлена и трансляция счетов не настроена;



● учет по РСБУ с
трансляцией записей хозяйственных операций
— отметка Используется учет по новым стандартам (ЕПС) не установлена, но
подготовлена и настроена трансляция счетов (запись проводок выполняется по РСБУ
и по ОСБУ на счета ЕПС выполняется одновременно);






● учет ведется только
по ЕПС без трансляции — отметка Используется
учет по новым стандартам установлена, ранее настроенные параметры трансляции не
применяются (выполняется запись проводок только по счетам ЕПС, по счетам РСБУ запись
не производится).



Настройка трансляции определяется заполнением
соответствующих регистров и описывается в разделе руководства Правила
определения лицевых счетов при использовании ЕПС.





Важно! Установка параметров учетной политики выполняется один
раз в начале учетного периода (прим. начало учетного периода принято от
даты начала года).
