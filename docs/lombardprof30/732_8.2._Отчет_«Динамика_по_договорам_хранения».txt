# 8.2. Отчет «Динамика по договорам хранения»



Отчет Динамика по договорам
хранения предназначен для сравнения в двух аналогичных периодах информации
по договорам хранения имущества и позволяет анализировать прирост в сравнении с
аналогичными прошлыми периодами. Особенности отчета:



● Период отчета – задает ограничение периода, за который
будут выбраны данные, а Шаг периодов сравнения — сдвиг времени назад для
получения аналогичного периода;



● Количество периодов сравнения – возможность
дополнительно указать необходимое количество прошлых периодов;



● Шаг периодов сравнения – значение не может быть меньше
Периода отчета, иначе не удастся осуществить сдвиг периода назад.






Отчет отражает информацию по
следующим показателям:



● Количество договоров хранения вещей, заключенных за отчетный
период ломбардом;



● Общая сумма денежных средств, полученных за отчетный период
ломбардом, по договорам хранения вещей.
