# 2.2.2. Правила определения лицевых счетов и их номеров



Конфигурация «Ломбард» предоставляет
возможность загрузки стандартных правил трансляции операций по РСБУ в операции
по ЕПС. Загрузка набора правил осуществляется путем выбора в панели разделов Администрирование и настройка НФО в группе Сервис и ссылки Загрузка мэппинга счетов, производится в случае, если учета ведется на счетах
РСБУ и последующей трансляции в счета ЕПС с применением определенных правил.






Форма
загрузки данных для трансляции счетов содержит следующие данные:



● 
Период —
указывается дата начала действия правила, указанные правила действуют только
после этой даты;






● 
Организация —
выбирается то предприятие, для которого будет действовать правило: если
значение не выбрано, то с указанной даты, правила трансляции будут
использоваться для всех записей справочника Организации, по которым ведется
учет в информационной базе.






Загруженные правила хранятся в
регистре Правила определения лицевых счетов. Обращение к регистру
выполняется из раздела программы Администрирование
и настройка НФО секции Настройка
трансляции и формирование лицевых счетов.








Важно! Программа предоставляет возможность редактировать
правила определения лицевых счетов вручную.






Для того, чтоб вручную настроить
соответствие счетов РСБУ и ЕПС нужно перейти в регистр Правила определения лицевых счетов и выполнить ввод нового правила определения лицевых счетов по
команде Создать.






В форме сведений для правила
определения лицевых счетов выполняется заполнение реквизитов следующими
данными:



● Период — указывается дата начала действия правила,
после этой даты будут действовать правила определения лицевых счетов;



● Организация — заполняется организация, для которой
будет действовать правило, если не заполнять, то указанное правило будет
действовать в любой организации;



● Счет РСБУ и Счет ЕПС — задается соответствие счетов;



● Фильтр — устанавливается правило отбора проводки по
РСБУ (на рисунке ниже правило трансляции будет действовать только для
физических лиц, см. далее раздел руководства Справочник
«Отбор проводок»;






● Правило определения номера — служит для заполнения правил
формирования номера лицевого счета (если правило не определено, создать его
можно в регистре Правила определения номеров лицевых счетов);



● Инвертировать проводку — применяется в случае, когда
устанавливается соответствие между счетами РСБУ и ЕПС разных видов, например:
для установки правил трансляции для активного забалансового счета РСБУ 008.01
на пассивные забалансовые пассивные счета ЕПС 91312 и 91312.






Новая запись
в форме списка Правила определения номеров лицевых счетов выполняется командой по кнопке Создать.






При создании открывается форма Правила
определения номеров лицевых счетов. Для каждого правила рекомендуется
задавать собственное наименование.





Важно! Первые 9 знаков лицевого счета определяются по
основным признакам, которые описаны в разделе Лицевые
счета в НФО данного
руководства Пользователя.









В открывшейся форме необходимо
установить следующие параметры:



● Указать правила для определения кода валюты и кода
доверительного управления (15 символов) — отметка устанавливается при
необходимости изменения кода валюты или кода доверительного управления и заполнения
15 знаков вместо 11;



● Количество разрядов — указывается то количество
знаков, которые будут использоваться в лицевом счете (без установленной отметки
сумма знаков по столбцу должна составлять 11, а с установленным признаком —
15);



● Источник — вид поля, по которому будут определяться
символы лицевого счета: Фиксированное
значение – при указании источника означает, что в лицевой счет будет попадать
определенный набор цифр, виды полей как Организация
и Подразделение означают, что в
лицевой счет будет попадать одно из свойств организации или подразделения
(например: код, ИНН, КПП и т.п.);



● Вид субконто — это данные, необходимые для
формирования лицевого счета, которые берутся из аналитических разрезов счета по
ЕПС если поле Источник содержит значение Из
субконто (при заполнении
этого значения необходимо выбрать вид субконто, из которого будут формироваться
данные для определения счета);



● Правило определения кода — выбирается одно из свойств
субконто, которое описывает числовое значение, например, в качестве кода может
быть код у контрагента в справочнике, ИНН контрагента, ОКПО и т.д.






В том случае, когда списки объектов
аналитического учета (субконто) на счетах по РСБУ и ЕПС отличаются, необходимо
заполнить отдельно Субконто счета
ЕПС. По умолчанию, объект аналитического учета (конкретное значение
субконто) по счету плана счетов РСБУ при трансляции переходит в совпадающий с
ним по типу объект аналитического учета на счете ЕПС.
