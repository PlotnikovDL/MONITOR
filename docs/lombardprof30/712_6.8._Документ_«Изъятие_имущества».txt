# 6.8. Документ «Изъятие имущества»



Документ предназначен для оформления процедур
изъятия правоохранительными органами предметов залога и вещей, находящихся на хранении.



Список документов открывается по
ссылке Изъятие имущества из раздела программы Ломбард — Продажа
и изъятие залогового имущества.






Для того что бы создать документ Изъятия
имущества необходимо заполнить обязательные поля Клиент, Основание
изъятия, Орган, произведший изъятие, а также Данные должностного лица.
На вкладке Расчет условий договора необходимо выполнить команду Рассчитать
стоимость.









В случае изъятия имущества начисления
по договору прекращаются.



При записи хозяйственных операций
документ формирует проводки по общехозяйственному плану счетов.






Также выполняется запись операций по
единому плану счетов отраслевого стандарта учета Банка России для НФО.
