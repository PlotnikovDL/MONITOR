# 10.1.8. Реализации изделий из ДМДК юридическим лицам и индивидуальным предпринимателям с использованием исходящей спецификации



Документ Спецификация ГИИС ДМДК (исходящая)
оформляется после проведения операций по реализации изделий из ДМДК юридическим
лицам или индивидуальным предпринимателям, а также при перемещении таких изделий
между территориально обособленными подразделениями (ТОП) организации.



После проведения документов Реализация
залоговых изделий, Авизо по займам (исходящее) или Перемещение по
договорам займа и хранения на вкладке Страница к оформлению раздела документа
Спецификация ГИИС ДМДК (Исходящая) формируются уже записи со статусом Отсутствует
для последующего оформления.






Для создания нового документа Спецификация
(Исходящая) необходимо на вкладке Страница к оформлению раздела Спецификация
ГИИС ДМДК (Исходящая) в списке выбрать документ, по которому оформляется спецификация,
и выполнить команду Оформить. В открывшейся форме документа Спецификация
(Исходящая) следует проверить заполненные значения, после чего:



● если заполняется спецификация по перемещению между территориально
обособленными подразделениями (ТОП), следует применить команду Провести,
далее выполнить команду Зарегистрировать спецификацию», далее – Подписать
и следом Обновить статус;



● если заполняется спецификация по реализации изделий из
ДМДК, следует применить команду Провести, далее Зарегистрировать спецификацию
(подписание направленной спецификации производится в личном кабинете участника
в ГИИС ДМДК) и после подписания документа в ГИИС ДМДК выполнить запрос на обновление
статуса из документа Спецификация (Исходящая) по команде Обновить статус.



Спецификации, оформляемоя для перемещения
между территориально обособленными подразделениями (ТОП) имеет свои
особенности.






Спецификация, оформляемая для реализации
изделий из ДМДК также имеет свои особенности.






После регистрации Спецификации (исходящая)
документ отразится в списке на вкладке Оформленные спецификации раздела в
документе Спецификация ГИИС ДМДК (Исходящая).
