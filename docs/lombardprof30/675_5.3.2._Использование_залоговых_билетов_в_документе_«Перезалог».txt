# 5.3.2. Использование залоговых билетов в документе «Перезалог»



Сведения об оформлении документа Перезалог описаны в разделе руководства
пользователя Перезалог. Поля для
ввода залогового билета располагаются в шапке документа.






Ввод залогового билета осуществляется
посредством автоматического подбора первого свободного залогового билета или путем
ручного выбора залогового билета. Список свободных залоговых билетов зависит от
заполнения реквизитов Организация, Склад, Подразделение. Перед тем
как подбирать залоговый билет необходимо вначале внести информацию по организации,
подразделению и складу, по этим полям выполняется отбор бланков.



Вид бланка менять нельзя. Его вид должен
быть таким же, как и в первичном документе Выдача
займа, получение залога.



Далее, выполняется автоматический подбор
залогового билета или ручной подбор залогового билета по команде Подбор бланка. Для выполнения
подбора бланков открывается специальная форма. Механизм подбора одинаковый и работает
так же, как и в других документах, связанных с операциями по залоговым билетам.






При выборе (двойное нажатии левой кнопки
мыши по строке) данные бланка переносятся в документ учета.






При проведении документа по
перезалогу в регистре Состояния бланков формируется новая
запись по указанному залоговому билету со статусом Оформлен, а данные по
старому залоговому билету попадают в регистр с состоянием Перезалог.






Также при проведении документа изменяется
информация по договору контрагента, который был создан при оформлении выдачи займа.
В нем отражаются уже данные (наименование, номер и др.) по новому залоговому билету.
