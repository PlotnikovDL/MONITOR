# 2.1.9. Счета учета номенклатуры



Для ввода новой записи необходимо использовать
команду Создать. В открывшейся
форме записи сведений по счету номенклатуры заполнить следующие данные:



● Вид номенклатуры — устанавливается значение вида номенклатуры,
если не заполняется, то указанный счет будет использоваться для учета при любом
виде номенклатуры;



● Номенклатура — выбирается конкретная позиция номенклатуры
из справочника Номенклатура если необходимо установить счет учета только для отдельного
элемента или группы, если нужно установить счет для всех элементов, входящих в группу;



● Организация — указывается организация, для которой выполняются
настройки, если не заполнять, то указанный счет будет использоваться для учета в
любой организации;



● Склад — указывается склад, если не заполнять, то указанный
счет будет использоваться для учета на любом складе;



● Тип склада — указывается тип склада, если не заполнять,
то указанный счет будет использоваться для учета с любым типом склада;



● Счет учета — необходимо указать счет, на котором будет
учитываться соответствующая номенклатура.



Для счета учета номенклатуры существует
возможность заполнения счетов НДС, которые будут отражаться документах поступления
и реализации данной номенклатуры.






Если поле Номенклатура оставить незаполненным, а заполнить только поля Склад (или Тип склада) и Вид номенклатуры,
то указанный счет учета будет устанавливаться в документах с выбранным складом или
типом склада для всех номенклатурных позиций с соответствующим видом номенклатуры
(при условии, что для группы номенклатуры не установлен иной счет учета).
