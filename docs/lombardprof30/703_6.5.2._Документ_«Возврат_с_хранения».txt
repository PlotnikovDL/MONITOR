# 6.5.2. Документ «Возврат с хранения»



Документ используется для оформления прекращения
обязательств по договору хранения имущества поклажедателя, создается на основании
документа Прием на хранение.






Посмотреть документы можно путем выбора
ссылки Возврат с хранения на панели
разделов Ломбард — Хранение.






В созданном документе Возврат с хранения на основании документа
(из документа) Прием на хранение все поля заполняются автоматически данными из документа
основания.



После проведения документа Возврат с хранения по РСБУ формируются следующие
записи хозяйственных операций в Кредит счета 002 по выбытию актива.






Аналогично при записи движений документа
по счетам ЕПС формируются также проводки и записи по регистрам учета вещей на
хранении, начислениям и займам, состояниям залоговых билетов.






На основании документа Возврат с хранения для отражения факта внесения
сумм в системе оформляется документ Поступление
наличных.
