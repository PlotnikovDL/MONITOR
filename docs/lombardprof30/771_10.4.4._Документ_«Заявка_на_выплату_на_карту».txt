# 10.4.4. Документ «Заявка на выплату на карту»



Документ предназначен для безналичной
выплаты на карту клиента, а также для получения печатной формы Заявление на выплату средствами интеграции
с сервисом «Lombard Payments».



В
интерфейсе документ доступен по команде Выплатить на карту из подменю по
кнопке Lombard
Tech документа Выдача
займа, получение залога.






Режим работы с документов включает в себя
два сценария:



● формирование печатной формы «Заявление на выплату» с помощью
сервиса «Lombard Payments» — данный сценарий отрабатывается когда признак Документы
подписаны не установлен.



● непосредственная выплата на карту клиента — при установленном
признаке Документы подписаны.



Оба сценария отрабатываются по команде
Выплатить
на карту из встроенного меню по кнопке Lombard Tech документа.






При вводе документа в шапке нужно указать
следующие реквизиты:



● Организация — организация, по которой регистрируется заявление
на выплату.



● Подразделение — подразделение организации.



● Клиент – физическое лицо, на карту которого будет производиться
выплата. При этом по гиперссылке Данные клиента необходимо убедиться в заполнении
следующих реквизитов физ. лица:



- 
Фамилия — фамилия физ. лица клиента;



- 
Имя — имя физ. лица клиента;



- 
Отчество — отчество физ. лица клиента;



- 
Дата рождения — дата рождения физ. лица клиента;



- 
Серия — серия паспорта физ. лица клиента;



- 
Номер — номер паспорта физ. лица клиента;



- 
Телефон — домашний телефон физ. лица клиента;



● Залоговый билет — договор, по которому необходимо осуществить
выплату;



● Банковская карта клиента – карта, на которую будет осуществляться
выплата, по гиперссылке Данные карты необходимо
убедиться в заполнении следующих реквизитов карты:



- 
PAN-номер карты — маскированный PAN-номер карты;



- 
Имя держателя — имя держателя карты латинскими буквами;



- 
Хэш карты — хэш зарегистрированной в сервисе Lombard Payments карты
клиента;



● Провайдер выплаты — выбирается из списка доступных провайдеров
выплаты (при выборе провайдера заполняются поля Лимит выплаты и Тип лимита);



● Сумма — сумма выплаты, размер не должен превышать значение
Лимит выплаты;



● Документы подписаны — признак для применения сценария выплаты:
получение печатной формы и непосредственно саму выплату;



● Проверен по базе террористов — признак необходимо устанавливать,
если клиент не прошел проверку в сервисе «Lombard Payments» (при частичном совпадении
сервис сообщает, что проверка не пройдена и необходима ручная проверка, в этом случае
пользователь должен самостоятельно проверить клиента по базе сведений, установить
данный признак и повторить операцию выплаты, если сервис обнаружит полное совпадение
— дальнейшее выполнение операции выплаты невозможно);



● Назначение платежа — строка назначения платежа.
