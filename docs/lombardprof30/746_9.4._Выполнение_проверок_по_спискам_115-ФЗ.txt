# 9.4. Выполнение проверок по спискам 115-ФЗ



Проверка контрагентов по реестрам производится
согласно установленным настройкам в Функциональности ломбарда, дополнительно
можно установить выполнение проверки регламентным заданием по расписанию или выполнить
проверку вручную из карточки физического лица.






Для проверки формируется Регламентное
задание на выполнение проверки по расписанию.






Также в решении присутствует ручная проверка,
которая выполняется из карточки физического лица.






Дополнительно в справочниках Физические лица и Контрагенты для
пользователей присутствует возможность получить историю проверок по спискам 115-ФЗ
и т.д.
