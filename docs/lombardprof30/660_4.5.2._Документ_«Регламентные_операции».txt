# 4.5.2. Документ «Регламентные операции»



Для того, чтобы сделать переоценку валютных
средств, начисление транспортного, земельного, имущественного налога, амортизации
по основным средствам и нематериальным активам, рассчитать налог на прибыль, необходимо
использовать регламентные операции, для этого следует на панели разделов Учет НФО — Регламентные операции НФО выбрать ссылку Регламентные операции.






При создании регламентной операции предлагается
сразу выбрать и ее вид из предопределенного списка.






Кроме указания вида операции следует
заполнить следующие поля:



● Дата — дата, на которую проводятся вычисления и
обработка данных;



● Организация — указывается организация, для которой проводится
регламентная операция;



● Ответственный — пользователь, выполняющий регламентную
операцию, значение заполняется автоматически;



● Комментарий — заполняется в произвольной форме краткая
информация по операции;



● Состояние — указывается статус выполнения (значение «выполнено»
или «не выполнено») регламентной операции, само значение заполняется автоматически
по результату выполнения операции.
