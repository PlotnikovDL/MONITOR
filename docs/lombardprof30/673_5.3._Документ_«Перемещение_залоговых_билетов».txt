# 5.3. Документ «Перемещение залоговых билетов»



Документ Перемещение бланков располагается в разделе программы Ломбард — Учет бланков. Переход в список документов выполняется по
ссылке Перемещение бланков.






Заполнение документа Перемещение бланков
выполняется по следующим реквизитам:



● Организация — организация, у которой будет происходить
перемещение бланков;



● Отправитель — склад, с которого будут переносить залоговые
билеты;



● Получатель — склад, на который будут переносить залоговые
билеты;



● Подразделение отправитель — подразделение, с которого будут
переносить бланки;



● Подразделение получатель — подразделение, на которое будут
переносить бланки;



● закладка Бланки — в данной закладке в табличной части вводится
информация о переносимых залоговых билетах.



Залоговые билеты вводятся по диапазонам
номеров. В колонке таблицы на закладке Бланки в поле Вид бланка указывается название/вид бланка.
В колонке Серия — серия залоговых билетов. В колонке Начало
диапазона указывается первый номер залогового билета в диапазоне. В колонке
Конец
диапазона указывается последний номер залогового билета в диапазоне.
Если списывается один залоговый билет, его номер указывается и в начале, и в конце
диапазона. Колонка Количество расчетная и не
редактируется, необходима для контроля количества перемещаемых залоговых билетов.






При необходимости можно выполнить заполнение
залоговых билетов с помощью команды Подбор.






В подборе имеется возможность быстрого
поиска залогового билета по серии и номеру. В поле Найти (серия) указывается
серия (или часть серии), которую требуется найти. В поле Найти (номер) указывается
номер (или часть номера), который необходимо найти.



При проведении документа в регистр сведений
Состояния
бланков записывается информация по номерам бланков со статусом Принят.






Также в документе при проведении и по
команде Проверить осуществляется
проверка на саму возможность перемещения бланка.






Установлены следующие критерии проверки
при выполнении процедур контроля:



● при перемещении залогового билета проверяется, был ли залоговый
билет отражен в системе со статусом Принят;



● списанные и оформленные залоговые билеты не перемещаются.



● перемещаемый залоговый билет должен числиться в подразделении,
которое указано в документе в поле Подразделение
отправитель;



● перемещаемый залоговый билет должен числиться на складе,
который указан в документе в поле Отправитель.



В результате проверки отображается таблица
с залоговыми билетами, которые не подходят для перемещения. В таблице выводятся
залоговые билеты по номерам, подразделениям, складам и их текущим состояниям. Красным
цветом выделяются залоговые билеты, которые не прошли проверку, а также те, которые
не подходят по критериям выбора.
