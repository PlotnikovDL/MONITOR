# 2.2.4. Переформирование лицевых счетов



Обработка по переформированию лицевых
счетов в проводках, которые были сформированы до настройки лицевых счетов,
предназначена для изменения правил формирования лицевых счетов непосредственно
в учете в организации без дополнительного проведения документов. Обработка
выполняется после настройки лицевых счетов, ее выполнение производится из
раздела программы Администрирование и
настройка НФО — Сервис по ссылке Переформировать лицевые счета.








Важно! Обработка Переформирование
лицевых счетов выполняется при изменении правил формирования лицевых счетов
Процедура предназначена для отражения изменений политики формирования лицевых
счетов непосредственно в учете организации без дополнительного проведения
документов.






Для выполнения обработки требуется
заполнить форму:






В форме обработки по переформированию
лицевых счетов заполняются следующие поля и настройки:



● в поле Период указывается период, за который будут
переформированы лицевые счета в проводках;



● в поле Счета указываются счета ЕПС, по которым будут
переформированы лицевые счета;



● отметка В иерархии устанавливается, когда необходимо
использовать подчиненные счета к счетам, указанным в поле Счета. Например, если
в поле Счета указывается счет с номером «610», то лицевые счета будут
переформировываться по счетам второго порядка 61002, 61003 и т.д.;



● отметка По всем счетам устанавливается, если
необходимо переформировывать лицевые счета по всем счетам ЕПС (поле Счета при
установке отметки не заполняется);



● отметку Из символа устанавливается тогда, когда
необходимо переформировать лицевые счета по счетам ЕПС, которые начинаются с
символа, указанного в поле Первый символ (при установке отметки у реквизита Из
символа поле Счета не заполняется);



● отметка Из правила устанавливается в том случае, когда
необходимо переформировать лицевые счета по одному определенному правилу, и
если данное поле не заполняется, то лицевые счета заполняются в соответствии с
настройками, сделанными в правилах определения лицевых счетов.
