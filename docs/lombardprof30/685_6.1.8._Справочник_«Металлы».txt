# 6.1.8. Справочник «Металлы»



Справочник «Металлы» используется для установки свойств предметов залога и
вещей на хранении с типом «Ювелирное
изделие».



Для драгоценных металлов ключевым
свойством при оценке является проба. Список доступных проб для конкретного
металла указывается непосредственно в форме справочника, в дальнейшем
выбирается в свойствах предметов.



Для возможности расчета стоимости
металла в изделии при выдаче займа или приеме на хранение необходимо заполнить
поле «базовая проба».



Для всех проб металла устанавливается
коэффициент пересчета к базовой пробе (коэффициент у базовой пробы
устанавливается равным, что позволяет оценить стоимость грамма металла любой
пробы, установив стоимость для грамма базовой пробы.



Для того, чтобы открыть список
элементов справочника Металлы и затем создать новый элемент, необходимо
выбрать и открыть ссылку Металлы на панели разделов Ломбард:
Настройки — Оценка металлов.






Далее по кнопке Создать или
с помощью пиктограммы «Копировать» создается новый
элемент справочника металлов, где указывается наименование металла и базовая
(основная) проба, по отношению к которой в дальнейшем будут указываться
коэффициенты пересчета цены за грамм.






При создании необходимо заполнить
информационные поля:



● Наименование;



● Базовая проба;



● Код по справочнику для РФМ;



● Химический знак;



● 
Список проб






Редактирование элемента справочника
выполняется таким же образом, как и для большинства справочников конфигурации.
