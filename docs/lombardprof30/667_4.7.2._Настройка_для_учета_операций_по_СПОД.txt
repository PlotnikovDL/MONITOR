# 4.7.2. Настройка для учета операций по СПОД



Перед началом ведения учета необходимо
установить дату окончания СПОД завершаемого периода путем выбора на панели разделов
Администрирование и настройка НФО — Сервис ссылки Дата окончания СПОД. После указания этой даты операции по СПОД
формироваться не будут.
