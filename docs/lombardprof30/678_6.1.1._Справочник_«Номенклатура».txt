# 6.1.1. Справочник «Номенклатура»



Справочник Номенклатура используется
ввода, обработки и хранения информации по предметам залога и вещей, принятых на
хранение. В справочнике указываются типы изделия и дополнительные свойства, различные
для каждого типа хранимых предметов.



Открывается справочник Номенклатура
из раздела программ Справочники — Товары
и услуги по ссылке Номенклатура.









При заполнении данными сведений по
номенклатуре следует обратить внимание на следующие реквизиты:






● Файлы — дополнительная информация об имуществе, сдаваемом
в залог (фотография, файл описания и пр.);



● Тип изделия — предопределенный справочник с заданными типами
изделий (ювелирное изделие, автомобиль, мех, прочее);



● Состояние — элемент справочника состояния, описывающего
стандартное состояние изделия (новый в упаковке, загрязненный, лом и т.д.).



● Вид изделия — классификация предметов залога для последующего
учета в отчетности (кольцо, браслет и т.д.);



Для разных типов изделий указываются присущие
им характеристики.



● Для ювелирных изделий:



- 
Металл — указывается
значение из справочника Металлы для типа
изделия, указанного как «Ювелирное изделие»;



- 
Проба — указывается
значение из справочника Пробы для типа
изделия, указанного как «Ювелирное изделие»;



- 
Вес — включая
общий вес, чистый вес и вес вставок.



● Для автомобилей:



- 
Марка — указывается
значение из справочника Марка для типа изделия, указанного как «Автомобиль»;



- 
Модель — указывается
значение из справочника Модель для типа изделия, указанного как «Автомобиль»;



- 
ПТС — записывается номер и серия паспорта транспортного средства.



- 
Дополнительная информация
о транспортном средстве (vin, госномер,
номер двигателя и т.п.).



● Для меховых изделий:



- 
Вид материала — указывается
вид материала, из которого сделано изделие;



- 
Размер — указывается
размер;



- 
Цвет — указывается
цвет.
