# 6.2.3. Документ «Установка действующих условий займа и хранения»



Документ используется для объявления актуальных
схем кредитования для ломбардов с определенной даты. Обратиться к документу можно
по ссылке Установка действующих условий займа и хранения из панели разделов
программы Ломбард: Настройки — См. также.






Форма элемента справочника Установка
действующих условий займа и хранения:






Новые условия займа и хранения
начинают действовать с даты документа при его записи и проведении.



Данные схемы можно привязать к
категориям клиентов и видам предметов залога, которые пользователь может
создать в справочниках категории клиентов и Виды изделий соответственно. В этом
случае у контрагента с определенной категорией будет доступна только часть
схем.



Если значения в полях
документа не заполнены, данные схемы применяются ко всем видам изделий и
категориям контрагентов
