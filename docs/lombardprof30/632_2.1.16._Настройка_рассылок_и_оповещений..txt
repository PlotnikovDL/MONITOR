# 2.1.16. Настройка рассылок и оповещений.



Для настройки рассылок и оповещений
необходимо перейти в раздел программы Ломбард:Настройки: Рассылки и
оповещения клиентов и выбрать ссылку Группы рассылок и оповещений.






В этой группе также относятся
отчеты Выполненные рассылки и Прогнозируемые рассылки, эти формы
расположены в подразделе Отчеты






Ввод новой записи выполняется по
кнопке Создать в форме списка Группы рассылок и оповещений (создание).






При заполнении необходимо установить
в каком виде будет производиться рассылка. Для этого требуется установить
отметки в информационных полях:



● Отправлять сообщение — вид отбора, по которому будет
производиться рассылка (контрагенту или физическому лицу);



● Отправлять email — управление отправкой почтовых сообщений, при ее
установке следует записать в поле Учетная запись адрес электронной почты на
который будет проводиться отправка сообщения;



● Отправлять по SMS — управление отправкой коротких
сообщений, установленная отметка требует указания номера телефона (для
контрагента по умолчанию установлено «телефон»; для физического лица необходимо
выбрать одно из значений: Мобильный телефон, Домашний телефон, Рабочий
телефон).



Следует иметь в виду, что для
отправки сообщений SMS требуется настроить общую
рассылку по SMS. Настройка выполняется при обращении к гиперссылке Настроить отправку по SMS









После выполнения команды Записать
становятся активными кнопки Создать рассылку и Создать вид оповещения. При выполнении команд открываются списки,
соответствующие тому или иному виду отправки оповещений.






Создать
рассылку — это рассылка рекламного
характера или оповещение об изменении условий кредитования.






При создании рассылки в открывшейся
форме списка по команде Создать.






открывается окно формы, отражающей основные данные для рассылки.



Номер при сохранении созданной рассылки будет
устанавливаться автоматически.



Созданную рассылку можно сохранить со
следующим Статусом:



● Черновик — рассылка не готова к отправке.



● К отправке — рассылка подготовлена к отправке,
согласно расписанию, установленному администратором системы по ней, будут
созданы сообщения получателям.



● Обрабатывается — в данный момент выполняется создание
сообщений по рассылке.



● Выполнена — рассылка обработана, все возможные
сообщения по рассылке созданы.






● Группа – название Группы соответствует заданному
наименованию Группы рассылок и оповещений, но при необходимости можно ее
сменить.



● Тема — текст, который отображается в заголовке
электронного письма, отражающего характер сообщения.



● Признаки Предназначена для электронных писем или Предназначена
для SMS устанавливаются автоматически, эти признаки параметры
устанавливаются автоматически, данные берутся из сведений по группам рассылки
оповещений.



● Состояние рассылки — выполнение команды по кнопке
Состояние рассылки открывает отчет, в отчет выводится информация о возможных
адресатах, созданных сообщениях и их статусах.



● 



● Сформировать отчет можно выполнив команду Состояние
рассылки, расположенную в командной панели формы Вкладка «Текст письма».







## Вкладка «Текст SMS сообщения»



Если рассылка предназначена для
отправки по электронной почте, то пользователю предоставляется возможность
добавления как приложения к письму различных файлов и выбор формата текста
сообщения в письме:



● Простой текст — недоступно форматирование текста,
размещение гиперссылок и картинок.



● HTML — доступно форматирование текста, размещение
гиперссылок и картинок.



В тексте письма указывается
информационная составляющая рассылки. Так же в сообщение кроме описания
допускается вставка индивидуальных параметров: Представление адресата и Текущая
дата.







## Вкладка «Адресаты»



На вкладке Адресаты можно установить фильтры на получение информации. В
зависимости от установленных/неустановленных отборов будет более или менее
точная адресная рассылка сообщений.







## Вкладка «Комментарий»



Во вкладке Комментарий
указываются пометки и расшифровки, которые в рассылку не войдут:



● Создать вид оповещения — рассылка информационного
характера с целью напомнить клиентам об их финансовых обязательствах перед
ломбардом;






● Наименование — название рассылки как в системе.



● Группа подтягивается автоматически из списка Групп
рассылок и оповещений. При необходимости можно изменить.



● Событие — выбор событий доступен из заранее
определенного списка. События могут возникать при изменении данных
информационной базы, либо при периодическом анализе данных информационной базы.



● Флаг «Оповещение активно» означает, что данное
оповещение актуально и выполняется.



● Флаг «Формировать сообщение за [Цифра] дней до
окончания срока/периода»: означает что за указанное количество дней, до
окончания срока/периода будет отправлено оповещение от том, что период
заканчивается.






● Шаблон электронного письма – заранее подготовленный
макет текстового сообщения, берется из сохраненного в рабочей папке
Пользователя сообщения в формате MS Word, при наличии шаблона достаточно выбрать необходимый
макет, а при его отсутствии сразу создать (при создании шаблона можно
персонализировать сообщение добавив параметры, применяя обычное перетаскивание
значений и текста из одного поля в другое с помощью компьютерной мышки).






Так же можно задать отбор для
сортировки отправления писем.






А также необходимо чтобы у
контрагента/физ.лица была заполнена в карточке контактная информация и установлены
отметки о согласии на рассылку.










## Отчет «Прогнозируемые рассылки»



Можно сформировать отчет по текущим
(выполненным) и прогнозируемым рассылкам.
