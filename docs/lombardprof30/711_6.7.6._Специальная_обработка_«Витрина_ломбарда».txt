# 6.7.6. Специальная обработка «Витрина ломбарда»



Обработка предназначена для предоставления
быстрого доступа к данным о предметах, находящихся на реализации и последующей быстрой
продажи таких предметов.



Основные возможности обработки Витрина
ломбарда позволяют выполнять быструю
навигацию к следующим спискам:



● 
Реализация залогового имущества; 



● 
Передача на реализацию; 



● 
Номенклатура.






Создание документа Реализация залогового имущества для продажи выбранных предметов.






Получение списка предметов на
реализации возможно с помощью фильтров отбора по следующим параметрам:



● Дата



● Номер



● Организация;



● Сумма продажи



● Комментарий



● Ответственный.



● Подразделение организации



Для
реализации предметов с витрины необходимо выполнить команду Добавить в
корзину, либо выбрать строку
списка, либо перетащить выбранную позицию в корзину.






Для
корзины существует также команда Очистить, позволяющая удалить все выбранные предметы из
корзины. Для удаления всех позиций следует выделить все строки списка.






После
того, как все предметы добавлены в корзину, выполняется команда Продать. При выполнении команды формируется и открывается новый документ Реализация залогового имущества.





Важно! При добавлении в корзину одного предмета из группы
предметов залогового билета остальные предметы залогового билета добавляются автоматически,
то есть продажа залогового билета происходить целиком.
