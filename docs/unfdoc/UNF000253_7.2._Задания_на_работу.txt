# 7.2. Задания на работу



Документ Задание на работу предназначен для планирования загрузки
сотрудников при выполнении работ, а также производства.



В форме документа
указывается Вид задания. В зависимости от
установленного вида с помощью документа могут быть запланированы:



■ работа
по какому-либо виду работ по конкретному заказу, по договору, для контрагента (Внешнее задание);



■ работа
по какому-либо виду работ для компании (Внутреннее задание).



Обязателен для
заполнения реквизит Сотрудник, в котором
указывается исполнитель задания, а также реквизит Подразделение.
Состав других реквизитов зависит от выбранного вида задания. Задание может
включать в себя произвольное количество работ и услуг, для которых
устанавливаются плановая продолжительность и трудоемкость. Для внешних заданий
также определяется стоимость.



Для регистрации
времени фактического выполнения задания на основании документа Задание на работу вводится документ Учет времени.



По заданиям на
работу может быть сформирован отчет по планированию и выполнению заданий.
