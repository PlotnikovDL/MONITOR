# 1.4. Ввод начальных остатков



Для ввода начальных остатков предусмотрены команды в
разделе Компания – Начальные остатки. Также
переход к вводу остатков доступен на начальной странице.






Заполнение остатков производится при помощи «Помощника
ввода начальных остатков». Помощник позволяет быстро ввести остатки для
основных разделов учета: Деньги, Товары, Расчеты, Прочее.



Перед началом заполнения необходимо определить дату ввода
начальных остатков. Для остатков по всем разделам учета дата будет единой. Дату
ввода остатков разрешено изменять, но стоит учесть, что все остатки будут
перемещены на новую дату.



В ходе заполнения пользователь поэтапно вводит данные по
всем основным разделам учета и заполняет сопутствующие справочники.






На последнем шаге помощника автоматически формируются
документы Ввод начальных остатков.
