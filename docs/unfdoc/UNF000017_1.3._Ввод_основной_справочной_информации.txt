# 1.3. Ввод основной справочной информации



Перед началом работы в информационной базе рекомендуем
заполнить основные справочники:



■ 
Организации –
информация об организациях, а также дополнительные сведения, необходимые для
ведения учета по ним в единой информационной базе. См. https://its.1c.ru/db/answers1c#content:930:hdoc.



■ 
Расчетные счета
организации – информация о расчетных счетах организаций.



■ 
Структурные единицы
– список организационно-структурных единиц компании: подразделений, складов и
магазинов (см. раздел «Подразделения»).



■ 
Номенклатура –
содержит список товаров, материалов, услуг (см. раздел «Ввод основной
информации о номенклатуре»).



■ 
Контрагенты –
содержит список компаний и частных лиц: поставщиков, покупателей и других
компаний, с которыми ваша организация заключает договоры (см. раздел «Покупатели»).



■ 
Сотрудники – список
сотрудников организации, данные о сотрудниках для целей кадрового учета и
расчетов по заработной плате (см. раздел «Сотрудники»).



Справочники можно заполнить путем загрузки из других
программ «1С», внешних файлов, сайтов и маркетплейсов. Загрузка выполняется из
раздела Компания – Начальные остатки. Узнайте
больше о загрузке:



■ 
из «1С:Управления торговлей 10.3» (https://its.1c.ru/db/metod81#content:8057:hdoc);



■ 
из «1С:Бухгалтерии» 3.0 (https://its.1c.ru/db/updinfo#content:862:1:issogl1_7);



■ 
из электронных таблиц форматов *.xlsx, *.mxl, *.csv (https://its.1c.ru/db/metod81#content:8033:hdoc);



■ 
из интернет-магазинов 1C-Битрикс и 1С-UMI (https://its.1c.ru/db/metod81#content:8129:hdoc);



■ 
из маркетплейса OZON (https://its.1c.ru/db/metod81#content:8050:hdoc);



■ 
из магазина ВКонтакте (https://its.1c.ru/db/metod81#content:7804:hdoc).
