# 13.8. Работа в облаке



В приложении
предусмотрена возможность перехода из «коробочной версии» в облачный сервис и
обратно.



Переход
выполняется в разделе Работа в облаке по ссылке Перейти в облачный сервис. Для переноса потребуется
указать адрес сервиса для переноса или выбрать перенос через файл выгрузки.






Порядок действий
для перехода в облачный сервис 1С:Фреш и другие способы переноса данных описаны
в статье https://1cfresh.com/articles/app_toservice.
