# 8.4. Выпуск продукции



Факт выпуска продукции по заказу регистрируется с помощью
документа Производство, который вводится на
основании документа Заказ на производство или как
самостоятельный документ. Заказ на производство считается выполненным, если
выпущена вся готовая продукция (полуфабрикат), указанная в заказе.



Список документов производства доступен по гиперссылке Производство в одноименном разделе. Список содержит
информацию о состоянии выполнения производства.



Закладка Заказы на производство
списка документов производства позволяет отражать факт выпуска продукции по
открытым заказам на производство.



По команде Оформить производство
можно оформить документы как по одному, так и по нескольким выделенным заказам
на производство.






Операция производства продукции (например, шкафа) отражается
документом Производство с видом операции Сборка. Документ содержит информацию о продукции и
комплектующих, использованных для выпуска, сырье и материалах, использованных
для ее изготовления, и отходах, возникших в процессе переработки. Данные
размещены в табличных полях закладок Продукция, Материалы и Отходы
соответственно.



Если документ создан на основании заказа на производство
или заказа покупателя, то его можно заполнить автоматически по нажатию кнопки справа от реквизита.






Закладка Материалы может быть
заполнена автоматически по спецификации выпущенной (разделанной) продукции с
помощью кнопки Заполнить.






Заполнять материалы для каждого выпуска (операции Сборка) не обязательно. Распределение материалов на
выпуск можно осуществить позже документом Распределение
затрат (например, сразу за день или смену).



Склад, откуда списываются материалы документом Производство, может быть задан один для всех материалов
или для каждой строки. Переключить режим отображения склада можно в контекстном
меню Шапка/табличная часть.



В документе Производство
предусмотрены реквизиты для указания: структурной единицы – изготовителя
продукции (склада или подразделения); места хранения материалов, использованных
для изготовления продукции; места хранения готовой продукции и возвратных
отходов, полученных на выходе производственной операции.



Если в качестве места хранения материалов указать склад
или какую-либо другую структурную единицу, отличную от
подразделения-изготовителя, то при отражении выпуска материалы будут
автоматически (самим документом Производство)
переданы в подразделение-изготовитель и отнесены на себестоимость выпускаемой
продукции. Аналогично, если указать структурную единицу – получателя продукции,
отличную от изготовителя, произведенная продукция будет автоматически
перемещена получателю готовой продукции.



Места хранения материалов, изготовитель и получатель могут
быть заполнены автоматически. Значения, подставляемые в документ Производство по умолчанию, можно задать в справочниках Склады и магазины и Подразделения (раздел
Компания) для любого склада или подразделения по
ссылке Просмотр и редактирование параметров
автоперемещения запасов.



Закладка Отходы в документе Производство предназначена для ввода списка отходов,
образовавшихся в процессе производства. Отходы, полученные в результате
производства продукции, могут использоваться как сырье для основного или
вспомогательного производства, для производственных или хозяйственных нужд
организации или для реализации на сторону.






Для учета возвратных отходов по ненулевой стоимости в
разделе Настройки – Еще больше возможностей –
Производство потребуется заполнить реквизит Вид
цены отходов, который будет применяться при оприходовании возвратных
отходов.



Для отходов указываются те же данные, что и для
материалов, за исключением цен. Стоимость образованных отходов определяется
переключателем:



■ 
Нулевая – отходы
приходуются на склад по нулевой стоимости;



■ 
Учетная –
возвратные отходы приходуются на склад по стоимости, рассчитанной по виду цен в
настройках. Себестоимость продукции, произведенной данной операцией, будет
уменьшена на сумму стоимости отходов. Распределение стоимости всех отходов на
продукцию происходит методом «распределение по количеству».



В поле Получатель отходов
необходимо выбрать структурную единицу типа Склад,
чтобы возвратные отходы были корректно учтены и появились как остаток на сладе.
