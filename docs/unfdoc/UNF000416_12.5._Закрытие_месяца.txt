# 12.5. Закрытие месяца



Для выполнения регламентных операций завершения периода в
управленческом учете предназначена обработка Закрытие
месяца, доступная по гиперссылке панели навигации в группе Финансовые операции раздела Компания.



Данная обработка автоматически выполняет следующие
регламентные операции:



■ 
Начисление амортизации,



■ 
Расчет прямых затрат,



■ 
Распределение затрат,



■ 
Расчет фактической
себестоимости,



■ 
Расчет курсовых разниц,



■ 
Расчет финансового
результата,



■ 
Зачет аванса по единому
налоговому счету.



Для корректного выполнения автоматических расчетов
необходимо, чтобы предварительно были введены все данные, относящиеся к
закрываемому месяцу.






Для операции Закрытие месяца
реализован механизм, позволяющий выявлять и исправлять в автоматическом режиме
ошибки и неточности, допущенные в ходе ведения учета. Проверка осуществляется в
группе Предварительный анализ по кнопке Выполнить.



Если в результате проверки обнаружены ошибки, напротив
операции появится значок .
Пользователь может перейти по ссылке ошибки, чтобы
получить информацию об ошибках и оперативно их исправить.



Закрытие месяца можно выполнять помесячно или сразу за
период. В режиме закрытия За период нужно выбрать
период, за который необходимо закрыть или отменить закрытие месяцев, после чего
эти операции будут последовательно выполнены по всем разделам учета.



Возможность будет полезна, если внесены изменения в
документы прошлых периодов, нужно выполнить повторное закрытие месяцев,
закрывать каждый месяц. Можно выбрать период, за который необходимо закрыть или
отменить закрытие месяцев, после чего эти операции будут последовательно
выполнены по всем разделам учета.






Если в информационной базе установлена Дата запрета редактирования, то при закрытии месяца
может выполняться автоматический перенос даты запрета редактирования на
последний день закрываемого периода. Для настройки переноса даты необходимо
включить опцию Переносить даты запрета редактирования в
разделе Настройки – Администрирование – Корректировка
данных.
