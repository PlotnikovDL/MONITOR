# 13.11. Почта, рассылки и SMS



По ссылке Почта, рассылки и SMS подраздела Интеграции
выполняется подключение основной учетной записи электронной почты для отправки
уведомлений из программы, а также настройка отправки SMS.



По ссылке Настройки почты выполняется переход к учетным записям
электронной почты пользователей и системной учетной записи.



Программа
поставляется с предопределенной системной учетной записью электронной почты,
которая используется для рассылки различных уведомлений из программы –
например, для автоматической отправки сообщений администратору по завершении
обновления программы. Для системных учетных записей рекомендуется сохранять
пароль, чтобы программа могла рассылать сообщения от такой учетной записи без
участия пользователя.



С помощью флажков Для отправки писем, Для получения
писем устанавливаются правила использования учетной записи.






Подключение почты
для пользователей описано в статье: https://its.1c.ru/db/metod81#content:8131:hdoc:1_1.



Настройка
отправки SMS дает возможность рассылать сообщения из программы с
помощью услуг оператора связи. Для возможности отправки SMS необходимо
заключить договор с провайдером на оказание соответствующей услуги. Подробнее: https://its.1c.ru/db/metod81#content:8250:hdoc.
