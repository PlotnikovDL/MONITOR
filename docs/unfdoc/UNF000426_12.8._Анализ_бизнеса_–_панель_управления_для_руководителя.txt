# 12.8. Анализ бизнеса – панель управления для руководителя



Прикладное решение позволяет получать оперативную
информацию о фактическом состоянии бизнеса, планировать деятельность компании:
составлять бюджеты по различным сценариям планирования на неделю, месяц,
квартал, год и контролировать в режиме реального времени соответствие
фактических результатов плановым показателям.



Такая информация доступна в инструменте Анализ бизнеса, который представляет собой три основных
отчета бизнеса: Доходы и расходы, Денежный поток, Баланс для
управления компанией, где можно увидеть три основных управленческих отчета: Доходы и расходы, Денежный поток
и Баланс. Отчеты формируются на основании
показателей бизнеса. Данные показателей могут быть получены из остатков и
оборотов по управленческим счетам, статьям движения денег и рассчитаны по
формулам.



Анализ бизнеса позволяет
получать информацию о фактическом и планируемом состоянии компании в наглядном
виде, а также сравнивать результаты в режиме план-факт.




## 12.8.1. Показатели бизнеса



В справочнике Показатели бизнеса хранятся
показатели для оценки бизнеса, такие как выручка, рентабельность,
маржинальность, точка безубыточности. Справочник формирует структуру бюджетов и
финансовых отчетов Анализ бизнеса (см. раздел «Отчеты «Анализа бизнеса»»).






Показатели являются составляющими, на основании которых
формируются три основных отчета инструмента «Анализ бизнеса»: Доходы и расходы, Денежный поток,
Баланс. Для каждого отчета создается и
используется свой набор показателей.



При старте работы список показателей автоматически
заполняется основными значениями. Пользователь может самостоятельно создать
новые показатели и правила получения данных по ним. Для показателя бизнеса
устанавливается Тип показателя, и в зависимости от
типа настраивается источник получения
данных (группа Источник).






Каждый показатель принадлежит одному из трех отчетов: Доходы и расходы, Денежный поток,
Баланс. Новый показатель добавляется в отчет, из
которого пользователь его создал. О том, как добавить новый показатель бизнеса,
читайте в статье: https://its.1c.ru/db/answers1c#content:1071:1.



Предусмотрена возможность создать показатель из любых
данных информационной базы. Такой показатель реализуется через внешнее расширение
конфигурации определенного формата. Для создания расширения требуются навыки
программирования в среде «1С» – рекомендуем обратиться к обслуживающей
организации.



Порядок создания произвольного показателя для отчетов
«Анализа бизнеса» описан в статье https://its.1c.ru/db/metod81#content:7878:hdoc.




## 12.8.2. Отчеты «Анализа бизнеса»



Анализ бизнеса состоит из
трех основных управленческих отчетов: Денежный поток,
Доходы и расходы, Баланс.
Отчеты можно найти в разделе Компания – Анализ бизнеса.



Для каждого отчета есть возможность выбрать период и
периодичность: месяц, квартал, полугодие, год. Доступен отбор по организации,
проекту или подразделению.



Для формирования отчетов с разной степенью детализации
используем варианты отчетов «Анализа бизнеса»:



■ 
Показатели – в
целом по бизнесу;



■ 
Подразделения – с
детализацией по подразделениям;



■ 
Проекты – в
детализации по проектам.



Строки отчетов представляют собой отдельные показатели
бизнеса, которые пользователь настраивает по своим правилам (см. раздел «Показатели
бизнеса»). Отображение всех трех отчетов можно переключать в
режимы: Факт, План, План / Факт.






Двойным кликом по ячейке отчета значения, полученные из
остатков и оборотов, детализируются до документов.






Все отчеты инструмента Анализ
бизнеса можно сохранить, распечатать, отправить по электронной почте или
включить в автоматическую рассылку отчетов. Для этого в форме присутствуют
соответствующие кнопки. Подробнее: https://its.1c.ru/db/metod81#content:8308:hdoc.




## 12.8.3. Панель управления для руководителя



Помимо трех основных отчетов в инструменте Анализ бизнеса есть возможность отслеживать цели
компании и контролировать основные показатели бизнеса на панели руководителя в
виде карточек «финансового ассистента». Панель руководителя находится на
закладке Ассистент в разделе Компания – Анализ бизнеса.



Информационная панель руководителя отображает информацию в
программе в виде цифр, графиков, диаграмм. Состоит из двух частей: «Цели» для
отслеживания и «Показатели» для контроля. Обновляется автоматически в режиме
реального времени.






Если открыть карточку цели, финансовый ассистент покажет,
каким образом рассчитаны суммы.






Карточки показателей бизнеса позволяют наглядно оценить
положение дел в компании по тем критериям, которые установил пользователь. Если
критерий оценки показателя не выполняется, карточка выделяется желтым цветом.






Если открыть карточку показателя, финансовый ассистент
оценит его значение и подскажет возможные действия для улучшения показателя.






Также непосредственно из карточки можно сформировать
рекомендуемые отчеты, открыть статью или инструкцию.



Набор карточек целей и показателей пользователь может
изменять: добавлять новые карточки, скрывать неактуальные и настраивать
имеющиеся.



Подробнее: https://its.1c.ru/db/metod81#content:8308:hdoc:3.




## 12.8.4. Оповещения об изменениях показателей «Анализа бизнеса»



Есть возможность получать регулярные отчеты по показателям
и уведомления об изменении показателей бизнеса. Оповещения настраиваются с
помощью инструмента «Ассистент управления нашей фирмой», категория навыков Даша, помоги контролировать. В
навыках ассистента можно настроить периодичность отправки оповещений, способ
отправки, список показателей и условия для отправки.



Подробнее: https://its.1c.ru/db/metod81#content:8171:hdoc:5.
