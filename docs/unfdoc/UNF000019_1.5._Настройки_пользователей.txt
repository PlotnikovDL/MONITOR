# 1.5. Настройки пользователей



Перед началом работы с прикладным решением может
потребоваться настроить работу нескольких пользователей. В этом случае
необходимо:



■ 
определить список пользователей;



■ 
назначить пользователям права доступа;



■ 
составить перечень ответственных лиц;



■ 
установить значения для подстановки по
умолчанию.



Определение списка пользователей и назначение им ролей
выполняются в разделе Настройки (подраздел Администрирование) по ссылке Настройки
пользователей и прав (см. раздел «Настройки
пользователей и прав»).
