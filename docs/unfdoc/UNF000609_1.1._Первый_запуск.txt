# 1.1. Первый запуск



При первом запуске информационной базы необходимо
заполнить данные о фирме в начальном окне программы. Стартовый помощник поможет
быстро произвести минимальные настройки и начать работу в программе.






Информация в разделе О себе позволит
заполнить данные первого пользователя учетной системы. Первому пользователю
автоматически будет присвоен профиль доступа Администратор.



Выбор вида бизнеса поможет установить основные настройки,
подходящие для конкретного рода деятельности. Например, для розничного магазина
включит возможность отражения розничных продаж в программе, использование
ручных и автоматических скидок, дисконтных карт, печать этикеток и ценников и
другие.



Сведения о юридических лицах
позволят заполнить карточку организации, установить систему налогообложения и
загрузить логотип. Для ввода данных о нескольких организациях используется
ссылка + Добавить организацию.
