# 3.3. Контактные лица



Введенные в карточку контрагента контакты хранятся в
соответствующем справочнике, к которому можно перейти по гиперссылке Контакты в разделе CRM.



В карточке контактного лица указываются представление
контактного лица, контактные данные, связанный контрагент и детали, такие как
пол, дата рождения, источник привлечения и прочее. В карточке контакта можно
сохранить файлы, возникшие при взаимодействии.



По кнопке + Свой реквизит
можно добавить дополнительные поля для ввода информации о контакте. Таким
образом, в информационной базе можно хранить полную информацию о каждом
контактном лице.
