# 13.10. Персональные настройки



Персональные
настройки пользователя выполняются в разделе Настройки
– группа Персональные настройки.



В панели Мои настройки доступны настройки текущего пользователя:
параметры для входа в программу, смена пароля (если это разрешено
администратором), просмотр прав доступа и настроек автозаполнения.



Также в панели
сгруппированы команды для настройки доступа к Интернету при использовании
прокси-сервера, настройки работы с файлами, подключения оборудования для
текущего пользователя, онлайн-поддержки.



По команде Настройки работы с файлами (группа Прочее подраздела Мои настройки) осуществляется персональная настройка
параметров работы с файлами. Задаются поведение программы при выборе файла,
режим открытия файлов, отображение информации при работе с файлом, настройки
открытия файлов.



Программа
позволяет хранить файлы, полученные напрямую со сканера. Для работы со сканером
в программе необходимо подключить сканер и произвести его настройку по ссылке Настройка сканирования. В зависимости от возможностей
подключенного сканера будут доступны те или иные параметры.



По ссылке Настройка рабочего каталога можно выбрать папку на
компьютере, в которой будут временно сохраняться файлы, полученные из программы
для просмотра или редактирования.



По ссылке Календари запускается настройка синхронизации с внешними
календарями. Подробнее: https://its.1c.ru/db/metod81#content:8065:hdoc:2.



По ссылке Почта и SMS можно выбрать основные учетные записи
электронной почты пользователя для получения и отправки писем.



По ссылке Мои учетные записи отображаются все подключенные учетные
записи электронной почты пользователя. Здесь же можно подключить новую учетную
запись. Подробнее: https://its.1c.ru/db/metod81#content:8131:hdoc:1_1.






С помощью ссылки Шаблоны писем, SMS пользователь может управлять
шаблонами сообщений. В справочнике можно создать «заготовки» на все возможные
случаи.
