# 11.4. Единый налоговый счет



С 1 января 2023 года для индивидуальных предпринимателей
(кроме ИП на НПД) стала обязательной уплата налогов одним платежом на
специальный счет. Налоги (авансовые платежи по налогам), сборы, взносы, а также
пени и штрафы уплачиваются в качестве единого налогового платежа (ЕНП) на
единый налоговый счет (ЕНС). Средства, поступившие на ЕНС, распределяются по
налоговым обязательствам налоговой инспекцией. Подробнее: https://its.1c.ru/db/taxenp.



Единым налоговым платежом нужно уплачивать большинство
установленных НК РФ обязательных платежей в бюджет. Список платежей: https://its.1c.ru/db/taxenp#content:3:hdoc.



Проверить состояние ЕНС и распределение средств можно в
личном кабинете налогоплательщика на сайте ФНС России. В программе реализован
прямой доступ к данным личного кабинета налогоплательщика с отображением
состояния ЕНС. Для обмена данными с личным кабинетом ЕНС потребуется
подключение сервиса «1С-Отчетность». Обновление данных личного кабинета будет
выполняться автоматически, без ввода пароля от ключа электронной подписи, если
отправить в ФНС согласие налогоплательщика на раскрытие налоговой тайны.



Для работы с ЕНС предназначен подраздел Единый налоговый счет в разделе
Налоги, состоящий из журналов Операции по счету,
Уведомления, Заявления о
зачете и интерактивной формы Личный кабинет ЕНС.



В инструменте Закрытие месяца для
автоматического зачета ЕНП в счет уплаты налогов и санкций выполняется
регламентная операция «Зачесть аванс по единому налоговому счету». Операция
распределяет баланс ЕНС по налогам из уведомлений и операций ЕНС и отражает в
учете. Операцию необходимо выполнять после сдачи отчетности и оплаты налогов в
конце месяца.



Подробнее: https://1c.link/to/gGg5jbr.




## 11.4.1. Личный кабинет ЕНС



Управлять единым налоговым счетом возможно напрямую из
«1С» без перехода на сайт ФНС. Для этого нужно подключить в программе Личный кабинет ЕНС. Возможность доступна для
пользователей сервиса «1С-Отчетность».



В личном кабинете налогоплательщика пользователи могут:



■ 
оперативно отслеживать состояние своего ЕНС по
аналогии с электронным кошельком;



■ 
видеть предстоящие платежи глазами налоговой
инспекции;



■ 
контролировать суммы задолженности;



■ 
получать расшифровку всех операций, которые
прошли по ЕНС;



■ 
сверять данные учета с данными налогового
органа.







## 11.4.2. Операции по ЕНС



Документ Операция по ЕНС
предназначен для отражения операций на едином налоговом счете, которые не
требуют отправки уведомлений. Документ формируется автоматически на основании
сумм налогов, рассчитанных к уплате в платежном календаре. При необходимости
может быть введен вручную.



Список документов Операции по ЕНС доступен
по ссылке Операции по счету.






Документом также можно отражать перенос переплаты или
недоимки по конкретным налогам на счет и другие операции по ЕНС.




## 11.4.3. Уведомления



С помощью документа Уведомление об
исчисленных суммах подается уведомление для тех налогов, которые
платятся до сдачи отчетности, то есть авансовым платежом. Документ формируется
автоматически на основании сумм налогов, рассчитанных к уплате в платежном
календаре. При необходимости может быть введен вручную.



Документы Операция на едином
налоговом счете и Уведомление об исчисленных
суммах налогов формируют одинаковые движения на едином налоговом счете.
Уведомление дополнительно отправляется в ФНС.







## 11.4.4. Заявления о зачете



Документ Заявление о зачете в счет
предстоящей обязанности используется для передачи в ФНС информации об
уменьшении налога УСН «Доходы минус расходы» на сумму страховых взносов. С
помощью документа также можно зачесть переплату по налогам на ЕНС в счет
предстоящей уплаты конкретного налога (сбора, страхового взноса).
